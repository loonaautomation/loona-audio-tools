聽力訓練 - 免費線上音程訓練器

簡而言之： 聽力訓練音程訓練器播放兩個音符，並要求您命名它們之間的距離——帶有即時反饋、執行中的分數和連勝，以及三個難度級別——完全免費，在您的瀏覽器中。

靠耳朵識別音程是唱準音調、轉錄歌曲和透過音樂考試背後的核心技能。此訓練器正是訓練這一點：一個根音、其上方的一個第二個音符，以及從半音到八度的十三種可能距離——由您選擇的難度級別縮小——每次都以半音解釋答案。

您聽到第一個音符，然後是更高的第二個音符。它們之間的距離是音程。初學者：《生日快樂》的第二個音符是向上的大二度；《一閃一閃亮晶晶》的前兩個音符在音高類上相距純五度——像這樣的錨點歌曲是音樂家學習音程的方式。

設計上的隱私： 聽力訓練聲音使用 Web Audio API 在您的瀏覽器中本地生成。沒有麥克風，沒有錄音，也沒有上傳任何東西——關閉選項卡，一切都消失了。

如何使用此工具

  1. 選擇難度：簡單達到純四度，中等達到小六度，困難達到完整的八度。
  2. 按“新問題”並收聽：第一個音符，然後是更高的第二個音符。
  3. 點選您認為聽到的音程。無論如何，正確答案都會變成綠色，並解釋半音數。
  4. 使用“重播”再次聽到這一對，或“一起播放”將兩個音符作為一個和絃聽到——然後按“新問題”並建立您的連勝。

常見問題

聽力訓練訓練器免費嗎？

是的。它完全免費，無需註冊，我們沒有強加限制。

什麼是音程？

兩個音符之間的音高距離，以半音為單位測量。純五度是 7 個半音——從 C 到 G 的距離。訓練器涵蓋從小二度（1 個半音）到純八度（12）的全部十三個音程。

問題和答案是如何檢查的？

問題生成器和音程表是經過測試的程式碼：在 500 多個生成的問題中，每個目標音符都正好是根音上方所選數量的半音，在 MIDI 數字和實際頻率上都是，並且每個名稱都與標準音程表匹配。

音程總是上行的嗎？

是的——在此訓練器中，第二個音符總是高於第一個。上行音程是標準起點；下行和和聲（一起）識別建立在它們之上，“一起播放”按鈕讓您初步品嚐和聲形式。

我到底如何進步？

錨點歌曲：為每個音程配一首您熟悉的、以它開頭的歌曲——半音是《大白鯊》主題曲，純五度是《一閃一閃亮晶晶》，八度是《飛越彩虹》。短暫的日常練習勝過偶爾的長時間練習。

工作原理

每個問題都由經過測試的程式碼生成：在舒適的範圍內選擇一個根音（A3 到 F4），在您的難度內繪製一個音程大小，目標音符在平均律中正好計算為根音上方那麼多半音。兩個音符都透過 Web Audio API 以乾淨的三角波音調和柔和的包絡播放——無取樣，無下載。

分數是簡單的記賬：已提問、正確和當前連勝，僅保留在此選項卡中。關閉頁面，分數重置——它是練習，而不是賬戶。

實際示例

一位合唱學生在一首新歌中總是錯過跳到五度的那一步。在中等難度上花十分鐘——大多數問題落在 5 到 8 個半音之間——她的分數從猜測變為連續答對 8 題，每次出現純五度時都能立即認出。

更多問題

為什麼兩個音程對我來說聽起來幾乎相同？

相鄰的音程（例如大三度與純四度）在大小上接近。降到簡單難度，直到小集合可靠為止，使用“一起播放”將這一對感受為一個聲音，然後再次擴大難度。

我可以用我自己的樂器訓練嗎？

是的——聽到一個問題後，在回答之前在您的樂器上找到那兩個音符。在真實樂器上與訓練器匹配是極好的綜合練習。

我的分數會儲存在任何地方嗎？

不會。分數僅存在於此選項卡中，關閉它時消失。您的練習的任何資訊都不會被儲存或傳送到任何地方。
