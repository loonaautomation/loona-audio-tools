音調生成器 - 免費線上測試音調生成器

簡而言之： 音調生成器以四種波形——正弦波、方波、三角波和鋸齒波——從 20 Hz 到 20,000 Hz 建立純測試音調，以測試揚聲器和耳機，為樂器調音，或檢查您的聽力範圍。即時播放或下載為 WAV。

測試低音炮是否真的能達到低音、檢查高音揚聲器是否仍在工作、將樂器調到 A440，或找到您仍能聽到的最高音高——設定頻率和波形，按下播放，音調在您的瀏覽器中實時生成。

設計上的隱私： 音調使用 Web Audio API 100% 在您的瀏覽器中生成——沒有要上傳的音訊檔案，也沒有傳送到伺服器。您生成的東西保留在您的裝置上。

如何生成測試音調

  1. 選擇波形——正弦波是純淨的參考音；方波、三角波和鋸齒波新增諧波，聲音逐漸變得更明亮。
  2. 使用滑塊、快速選擇按鈕設定頻率，或輸入從 20 Hz 到 20,000 Hz 的確切值。
  3. 設定時長（1-30 秒）和適中的音量——高音調可能令人不適，因此從低開始。
  4. 按“播放音調”收聽它，或“以 WAV 下載音調”將音調的立體聲 WAV 檔案儲存。

常見問題

音調生成器免費嗎？

是的。它完全免費，無需註冊，沒有水印。

有任何東西上傳到伺服器嗎？

不會。音調使用 Web Audio API 在您的瀏覽器內實時合成。WAV 下載也在您的裝置上建立。

它可以生成什麼頻率？

從 20 Hz 到 20,000 Hz——人類聽力的標準範圍。您是否真的聽到極端值取決於您的揚聲器或耳機以及您自己的耳朵：小型手機揚聲器無法再現 20 Hz，大多數成年人在 14 到 17 kHz 之間的某處停止聽到。

波形之間有什麼區別？

正弦波是單個純頻率。三角波是帶有微弱諧波的較柔和音調，方波是帶有強烈奇次諧波的空洞嗡嗡聲，鋸齒波是最明亮的，包含每個諧波。揚聲器測試通常用正弦音調完成。

為什麼 440 Hz 重要？

440 Hz 是音符 A4，國際標準音高，管絃樂隊以此調音。如果您在演奏 A 的樂器旁邊播放它，您可以調整樂器，直到兩者匹配。

工作原理

音調使用 Web Audio API 在您的瀏覽器內以數學方式合成——一個振盪器以您設定的精確頻率產生您選擇的精確波形。下載將相同的波形逐個取樣地渲染到標準 WAV 檔案中，因此您儲存的檔案與您聽到的相符。

實際示例

您買了一個額定低至 40 Hz 的小低音炮，想誠實地檢查它。您將正弦音調設定為 50 Hz，然後 40 Hz，然後 30 Hz，每個播放幾秒鐘。50 和 40 Hz 的音調被清楚地感覺到，30 Hz 的音調在此揚聲器上是無聲的——因此它在您房間中的真實限制約為 40 Hz，正如額定的。

一個安全提示：測試音調——尤其是高頻和方波——在相同的音量設定下可能比音樂刺耳得多。始終從低音量開始，慢慢提高。

更多問題

我可以用這個測試我的聽力嗎？

您可以透過慢慢提高頻率直到音調消失來探索您的聽力範圍取樂——但請保持音量低，並記住這不是醫學測試。正確的聽力檢查需要校準的裝置。

為什麼下載的 WAV 是立體聲？

下載在兩個聲道上包含相同的音調，因此它在雙耳中相同播放，並可在任何播放器或編輯器中作為測試檔案工作。

音調在非常低的音量步進下聽起來有噼啪聲——這正常嗎？

方波和鋸齒波音調由於其諧波而自然刺耳。對於平滑的參考測試，請使用正弦波形。
