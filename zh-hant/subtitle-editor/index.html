SRT 字幕編輯器 - 免費線上修復、移動和轉換字幕

簡而言之： 字幕編輯器在您的瀏覽器中開啟 SRT 或 WebVTT 字幕檔案，讓您糾正文字，重新定時單個字幕條，一鍵將整個檔案提前或推後移動，修復相互重疊的字幕條，並將結果下載為 .srt 或 .vtt——經典“字幕不同步”問題的直接修復。

下載的字幕在演員說話前幾秒出現、字幕有拼寫錯誤、字幕檔案格式不適合您的播放器——所有這些都是字幕檔案本身內部的問題，都可以透過編輯該檔案來修復。在下方載入它，在表格中進行更改，然後下載修復後的檔案。任何內容都不會上傳到任何地方。

如何編輯字幕檔案

  1. 點選上方框並選擇您的 .srt 或 .vtt 檔案——或將字幕文字貼上到框中，或按“載入示例字幕”先試用編輯器。
  2. 每個字幕條都出現在表格中。直接在任何“開始”、“結束”或文字框中鍵入以更改它；您的鍵入會隨進行而被接收。
  3. 要重新同步整個檔案，以秒為單位輸入移動量（例如 2.5 如果字幕提前顯示 2.5 秒， -2.5 如果它們顯示得太晚）並按“移動所有字幕條”。要僅移動檔案的一部分，填寫“從字幕條 #”和“到字幕條 #”，並使用“僅移動範圍”。
  4. 按“查詢重疊”以突出顯示在下一個開始時仍在螢幕上的任何字幕條，然後“修復重疊”以使每個這樣的字幕條正好在下一個開始處結束。
  5. 將修復後的檔案下載為 .srt，或如果您的播放器或網站需要該格式，則下載為 WebVTT (.vtt)。

常見問題

字幕編輯器免費嗎？

是的。它完全免費，無需註冊，沒有水印，我們沒有強加限制。

我的字幕檔案會上傳到伺服器嗎？

不會。您的字幕檔案 100% 在您的瀏覽器內讀取和編輯。它從不離開您的裝置，也不會儲存在任何地方。

此工具可以從影片或音訊檔案自動建立字幕嗎？

不會。此工具編輯已經存在的字幕檔案（SRT 和 WebVTT）。將語音自動變成字幕需要語音識別 AI，此工具不做這個——它是一個編輯器，而不是轉錄器。

SRT 和 WebVTT 之間有什麼區別？

SRT (SubRip) 是使用最廣泛的字幕格式——YouTube 和大多數影片播放器都接受它。WebVTT 是瀏覽器中 HTML5 影片播放器所用的網路標準。它們包含相同的字幕條；VTT 將小數分隔符寫為點而不是逗號，並以 WEBVTT 標題行開始。此工具開啟並儲存兩者，因此轉換隻是以另一種格式下載。

為什麼我的字幕相對於影片稍微提前或延遲？

通常字幕檔案是為影片的不同剪輯製作的——一個帶有更長介紹、被刪場景，或與您的不同的流媒體釋出的版本。如果每個字幕都偏差大致相同的量，在移動框中輸入該量（正數使字幕更晚，負數使字幕更早），並一鍵移動所有字幕。如果字幕一開始同步，但隨著影片播放而越來越遠，那是幀率不匹配（例如 23.976 fps 字幕對 25 fps 影片）——恆定的移動不能完全修復逐漸漂移。

工作原理

您的字幕檔案是純文字：字幕條列表，每個都有開始時間、結束時間以及一行或多行文字。此編輯器用您的瀏覽器讀取檔案，將每個字幕條變成表格的一行，並在您移動、排序或修復字幕條時對時間戳進行簡單的算術——內部儲存為確切的毫秒。下載然後被寫回為標準 SRT 或 WebVTT 文字，在您的裝置上生成。因為一切都是文字和算術，工具在頁面載入後可以離線工作，並處理帶有數千個字幕條的檔案。

實際示例

您為一部電影下載字幕，但每個字幕都提前 2.5 秒出現 之前 臺詞被說出——該檔案是為沒有錄音室介紹的版本製作的。您在此處載入 .srt，鍵入 2.5 在移動框中並按“移動所有字幕條”：一個讀作 00:00:07,000 --> 00:00:09,500 的字幕條現在讀作 00:00:09,500 --> 00:00:12,000，並且每個其他字幕條都移動相同的 2.5 秒。您下載 .srt，字幕與語音對齊。

同樣的想法修復單個壞部分：如果僅在插入場景之後的字幕條是錯的，只需將該範圍移動場景的長度。

更多問題

我可以在 YouTube 上使用下載的檔案嗎？

是的。YouTube 直接接受 .srt 上傳（字幕 > 新增語言 > 上傳檔案）。在此處將您編輯的檔案下載為 .srt 並上傳它——您設定的時間和文字正是 YouTube 將顯示的。

“修復重疊”確切地改變了什麼？

它檢視每對相鄰的字幕條。如果一個字幕條的結束時間晚於下一個字幕條的開始時間，第一個字幕條的結束會被拉回到正好下一個字幕條的開始，因此螢幕上一次只有一個字幕。它從不移動開始時間，也從不刪除文字。

我可以開啟哪些字幕格式？

SRT (.srt) 和 WebVTT (.vtt)。其他格式如 SSA/ASS 或 TTML 不受此編輯器支援——產生它們的大多數工具可以匯出 SRT 副本，然後您可以在此處編輯它。
