波形生成器

Loona Audio Tools 如何工作

  1. 選擇一個工具並新增您的音訊。 您的檔案由您自己的瀏覽器讀取——不傳送到任何地方。錄音機僅在您按下“錄製”時請求麥克風許可權。
  2. 剪下、合併或錄製。 拖動波形手柄，排列您的檔案，或說話——一切都在您的裝置上進行。
  3. 下載結果。 完成的音訊在您的裝置上建立，並立即下載。

為什麼人們信任基於瀏覽器的工具

大多數線上音訊網站要求您將您的歌曲、講座和語音錄音上傳到陌生人的伺服器。Loona Audio Tools 以相反的方式構建：處理程式碼來到您的音訊這裡，而不是反過來。這意味著更快的結果、隨處可用的隱私，以及您的任何東西都不會被儲存、記錄或共享。關閉選項卡，您的音訊的每個痕跡都消失了。

常見問題

Loona Audio Tools 真的免費嗎？

是的——每個工具都是 100% 免費的，沒有註冊、沒有水印，也沒有我們強加的每日限制。

我的音訊檔案會上傳到你們的伺服器嗎？

從不。每個工具都使用內建的 Web Audio 技術 100% 在您的瀏覽器中執行。您的檔案和錄音從頭到尾都保留在您的裝置上。

我可以使用哪些音訊格式？

剪下器和合並器接受您的瀏覽器可以解碼的格式——在所有現代瀏覽器中包括 MP3、WAV、M4A 和 OGG。匯出的檔案是標準 WAV，可隨處播放。

錄音機會將我的聲音傳送到任何地方嗎？

不會。錄音機完全在您的裝置上執行。您的麥克風僅在您按下“錄製”時開啟，錄音僅在您選擇下載時儲存。

支援哪些裝置？

手機、平板電腦或電腦上的任何現代瀏覽器——Chrome、Edge、Firefox 和 Safari 都可以。錄音機需要麥克風和使用它的許可權。
