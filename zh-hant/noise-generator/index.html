噪聲生成器 - 免費線上白色、粉色和棕色噪聲

簡而言之： 噪聲生成器製作三種經典顏色的噪聲——明亮的白色、均衡的粉色和深沉的棕色——用於睡眠、專注和掩蓋分散注意力的聲音，在您的瀏覽器中實時播放或下載為 WAV，完全免費。

不存在的風扇、永不停歇的雨、吞沒外面街道的隆隆聲——穩定的噪聲透過掩蓋變化的聲音幫助人們入睡、學習和工作。此工具與本站的音調生成器有意不同：那個工具以一個確切的頻率發出有音高的音調，而這個工具發出分佈在所有頻率上的無音高噪聲，並以三種不同的方式塑形。

對於迴圈：在任何設定為重複的播放器中播放下載——噪聲從第一秒到最後一秒統計上穩定，因此迴圈聽起來連續。從低音量開始，尤其是在使用耳機時。

設計上的隱私： 噪聲生成器使用 Web Audio API 在您的瀏覽器中本地建立每種聲音。沒有錄製、上傳或儲存任何東西——關閉選項卡，一切都消失了。

如何使用此工具

  1. 選擇噪聲型別：白色用於掩蓋尖銳的聲音和語音，粉色用於均衡的、雨聲般的專注和睡眠，棕色用於深沉的平靜隆隆聲。選單下方的說明解釋了每一種。
  2. 按“播放噪聲”——從低音量開始，尤其是在耳機上——並調整到舒適的電平。
  3. 要將聲音保留在此選項卡之外，選擇下載長度並按“以 WAV 下載”。
  4. 在任何開啟了重複/迴圈的播放器中播放下載的 WAV，以獲得連續的噪聲。

常見問題

噪聲生成器免費嗎？

是的。它完全免費，無需註冊，我們沒有強加限制。

白色、粉色和棕色噪聲之間有什麼區別？

這是關於能量如何在頻率上分佈。白噪聲在每個頻率上具有相等的能量，聽起來明亮且嘶嘶作響。粉紅噪聲每八度下降 3 dB，因此每個八度聽起來同樣響亮——均衡，像雨。棕色噪聲每八度下降 6 dB，並將能量堆積到低音——深沉的隆隆聲。

這與音調生成器有何不同？

完全不同的工作：音調生成器以確切的頻率發出一個有音高的音調（帶音符般音高的測試訊號）。噪聲生成器發出無音高的寬頻噪聲——同時數千個頻率，按顏色塑形——用於睡眠、專注和掩蓋。這兩個工具都不能做對方的工作。

哪種顏色最適合睡眠？

大多數人更喜歡粉色或棕色用於睡眠，因為降低的高頻在數小時內感覺更柔和。白色最能掩蓋突然的尖銳聲音。以低音量試聽每種幾分鐘——最好的就是您停止注意到的那一個。

它對嬰兒和我的聽力安全嗎？

保持音量適中——大約安靜談話的水平或更低，切勿將揚聲器靠近嬰兒的耳朵。合理音量的噪聲廣泛用於育嬰室；任何種類的響亮聲音，長時間，都對任何人的聽力不好。

工作原理

您選擇的噪聲在您的裝置上逐個取樣地生成。白噪聲是純隨機性。粉紅噪聲將該隨機性透過經典的 Kellet 濾波器組，它將其能量每八度向下傾斜 3 dB。棕色噪聲將其與溫和的洩漏整合，每八度向下傾斜 6 dB。所有三種都由經過測試的程式碼生成，其統計資料得到驗證：三種顏色的相關性和過零指紋以確切的預期順序出現（棕色最平滑，白色最粗糙），並且沒有采樣曾經削波。

播放迴圈一個生成的緩衝區；下載渲染一個正好是您所選長度的全新緩衝區，並使用音訊剪下器所用的相同經過測試的編碼器將其儲存為標準 WAV。

實際示例

一位教師在嘈雜的廚房桌旁批改試卷，透過一隻耳機低音量播放粉紅噪聲——嘈雜聲和談話聲融入背景，穩定的雨聲般的聲音讓她一口氣批改完一整摞試卷。

更多問題

為什麼下載不能持續數小時？

一小時的 WAV 噪聲，對於每秒統計上重複的聲音來說，將是數百兆位元組的檔案。30 秒或 60 秒的 WAV 迴圈播放，以微小的體積提供完全相同的聆聽結果。

我可以將噪聲與音樂或課程混合嗎？

是的——在任何其他音訊下安靜地播放噪聲。許多人將其保持在主聲音之下，剛好足夠填補分散注意力的噪聲之間的空隙。

如果我關閉選項卡，噪聲還會繼續播放嗎？

不會——與本站的一切一樣，聲音僅存在於此選項卡中。對於過夜使用，請下載 WAV 並在播放器應用中播放。
