螢幕錄影機 - 免費線上錄製您的螢幕

簡而言之： 螢幕錄影機捕獲您的螢幕、瀏覽器選項卡或單個視窗——完全免費，不上傳任何東西，影片下載為 WebM 檔案。

解釋一個錯誤、教授一節課，或向某人展示網站的工作原理，用一個快速影片比用十張截圖容易得多。按“開始”，選擇要共享的內容，做您的事情，然後下載錄音。當您想旁白時，您的麥克風可以混入。

設計上的隱私： 螢幕捕獲完全在您的瀏覽器內進行。錄音在您錄製時保留在瀏覽器的記憶體中，僅當您點選“下載”時才儲存。任何東西都不會上傳到伺服器，關閉選項卡會刪除一切。

如何錄製您的螢幕

  1. 如果您想旁白，勾選“麥克風音訊”；如果選項卡的聲音應被錄製，勾選“系統/選項卡音訊”（桌面版 Chrome 或 Edge）。
  2. 點選“開始錄製”，並在瀏覽器的選擇器中選擇要共享的內容：瀏覽器選項卡、視窗或整個螢幕。
  3. 做您想展示的事情——頂部的計時器顯示您已經錄製了多長時間。此選項卡保留在捕獲的背景中，而不是在其中，除非您共享整個螢幕。
  4. 點選“停止錄製”（或瀏覽器自己的“停止共享”欄）。觀看預覽，然後點選“下載錄音”以儲存 WebM 檔案。

常見問題

螢幕錄影機免費嗎？

是的。它完全免費，無需註冊，沒有水印，我們沒有強加錄製限制。

我的螢幕錄影會上傳到伺服器嗎？

不會。錄音在您錄製時完全在您的瀏覽器內捕獲和儲存，完成的檔案在您下載時在您的裝置上建立。從不上傳任何東西。

錄音以什麼格式下載？

Chrome、Edge 和 Firefox 中的 WebM（較新 Safari 版本中的 MP4）。WebM 在所有現代瀏覽器中播放，並直接上傳到 YouTube 和大多數其他平台。

我可以錄製電腦的聲音以及我的聲音嗎？

您的聲音：是的——勾選“麥克風音訊”並允許麥克風訪問。來自電腦本身的聲音（系統/選項卡音訊）僅在桌面版 Chrome 和 Edge 中工作，並且僅當您共享瀏覽器選項卡並在選擇器中勾選共享音訊選項時。其他瀏覽器無法捕獲系統音訊——那是瀏覽器限制，不是任何網站可以改變的。

哪些瀏覽器支援螢幕錄製？

桌面版 Chrome、Edge 和 Firefox 完全支援它。Safari 從 macOS 上的 14.1 版本開始支援它。在手機上，大多數移動瀏覽器不允許網站錄製螢幕——請為此工具使用桌面瀏覽器。

工作原理

當您按下“開始”時，您瀏覽器內建的螢幕捕獲功能 (getDisplayMedia) 顯示它自己的選擇器，並將您正好選擇的內容的實時影片流交給此頁面——不多。此頁面使用瀏覽器的 MediaRecorder 現場錄製該流。完成的影片在您瀏覽器的記憶體中組裝並作為下載提供；沒有伺服器看到過一幀。

實際示例

您想向學生展示如何在學校門戶上提交表格。您勾選“麥克風音訊”，點選“開始”，選擇帶有門戶的瀏覽器選項卡，在大聲解釋每個步驟的同時慢慢填寫表格，然後在 1 分鐘 40 秒後停止錄音。您預覽影片，下載 WebM 檔案，併傳送它——總成本為零，學生的資料從未接觸任何伺服器。

因為瀏覽器本身控制選擇器和“停止共享”欄，您始終掌控一切：錄音只能包含您選擇的內容，並且在您說停的那一刻結束。

更多問題

為什麼選擇器沒有提供任何音訊？

系統音訊僅在桌面版 Chrome 和 Edge 中提供，且僅適用於瀏覽器選項卡——視窗和全屏在這些瀏覽器中始終無聲。您的麥克風則透過“麥克風音訊”勾選框在每個受支援的瀏覽器中工作。

我的錄音沒有聲音——出了什麼問題？

檢查三件事：“麥克風音訊”框已勾選且許可權已允許；對於選項卡聲音，選擇器中的“共享選項卡音訊”開關已開啟；並且選項卡在錄製時確實在播放聲音。無聲的來源會錄製為靜音。

我可以錄製多長時間？

我們沒有限制，但錄音在您下載它之前保留在瀏覽器的記憶體中。非常長的錄音（數小時）可能會在較小的裝置上耗盡記憶體——對於長會話，請分部分錄制。

如果我按瀏覽器的“停止共享”而不是“停止”按鈕會怎樣？

那樣也可以。錄音完成，您的預覽和下載出現，就像您使用了此頁面上的“停止”按鈕一樣。
