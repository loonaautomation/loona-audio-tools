關於 Loona Audio Tools

簡而言之： Loona Audio Tools 是 Loona Automation 的一套免費的 3 款音訊工具，完全在您的瀏覽器中執行——您的音訊從不上傳到任何地方。

什麼是 Loona Audio Tools？

Loona Audio Tools 是免費的 3 款線上工具集合，用於日常音訊工作：音訊剪下器使用視覺化波形修剪 MP3、WAV、M4A 和 OGG 檔案，音訊合併器將多個音訊檔案合併為一條曲目，錄音機直接從您的麥克風錄音。

它是以下的一部分 Loona Automation，這是一系列免費的實用型網路工具，專為學生、教師、創作者、辦公室和小型企業打造——服務巴基斯坦及世界各地的使用者。

我們的不同：設計上的隱私

幾乎每個音訊網站都是將您的檔案上傳到伺服器來工作的。我們構建了相反的方式：所有處理都使用 JavaScript 和 Web Audio API 在您自己的瀏覽器內進行。您的音訊從不傳輸、從不儲存，我們也從不聆聽。錄音機僅在您按下“錄製”時開啟麥克風，並且僅在您錄製期間開啟。它更快，可在任何裝置上工作，並且這就是處理人們錄音的尊重方式。
