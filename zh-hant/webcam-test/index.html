常見問題

攝像頭測試免費嗎？

是的。它完全免費，無需註冊，對您測試的頻率沒有限制。

我的相機影象會上傳到任何地方嗎？

不會。您的相機僅在本地、在您自己的瀏覽器內使用。預覽、測量和任何快照都保留在您的裝置上——快照僅在您點選“下載”時儲存。任何東西都不會傳送到任何伺服器。

為什麼預覽像鏡子一樣移動？

預覽預設是映象的，因為那是您習慣於看到自己的方式，它使構圖自然。如果您在映象開啟時拍快照，照片按您所見儲存；如果您想要照片正如相機所見的場景（衣服上的文字將正確讀取），請關閉映象。

讀數說 720p，但我的相機是 1080p——為什麼？

讀數顯示瀏覽器實際接收的解析度，可能低於相機的最大值。光線、USB 頻寬、瀏覽器和其他使用相機的應用都會影響它。關閉其他使用相機的應用，改善光線，然後重新啟動測試，給它達到全解析度的最佳機會。

未找到相機——我應該檢查什麼？

檢查相機是否已插入（或在膝上型電腦上未被遮擋/禁用），沒有其他應用正在使用它，並且您已在瀏覽器的位址列設定中允許此網站的相機許可權。在 Windows 上，還要檢查“設定 > 隱私 > 相機”是否允許桌面應用。

工作原理

當您按下“開始”時，瀏覽器請求您的許可權並開啟您的相機，要求它提供它能提供的最佳質量。此頁面然後讀取相機流自己的設定——正在交付的確切寬度、高度和幀率——並直接顯示給您，沒有估計。快照將當前幀複製到您裝置上的繪圖畫布上，並將其變成標準 PNG 影象。

實際示例

您即將用一臺聲稱 1080p 的新 USB 攝像頭錄製一節課。您開始測試：畫面看起來柔和，讀數說 1280 x 720，30 fps。您關閉另一個正在使用相機的應用，在您面前加一盞燈，並重新啟動測試——現在讀數顯示 1920 x 1080。您拍一張快照來仔細檢查構圖，並錄製您的課程，確切知道您的學生將看到什麼。

數字重要是因為會議應用經常向您顯示一個隱藏真相的小預覽。測量真實流告訴您，柔和的畫面是相機、光線還是另一個應用在偷走質量。

更多問題

畫面暗或有顆粒——我如何修復它？

幾乎總是：光線。面對窗戶或在您面前放一盞燈（切勿放在身後），並給相機一秒鐘時間調整。顆粒感是相機在弱光下提高感光度的結果，所以光線越多，相同解析度下的畫面就越乾淨。

瀏覽器說相機被阻止——我如何解除阻止？

點選位址列左側的鎖定或設定圖示，找到“相機”，並將其設定為允許此網站。然後再次按“啟動相機”。

我可以將手機用作此測試的相機嗎？

是的——在您手機的瀏覽器中開啟此頁面，它將直接測試手機的相機。要將手機用作電腦的網路攝像頭，您需要在兩個裝置上都有單獨的伴侶應用，這超出了網頁能做的。
