鼓音序器 - 免費線上節拍製作器

簡而言之： 鼓音序器讓您在 16 步網格上構建鼓節奏——kick、snare、閉合和開口 hi-hat，全部在您的瀏覽器中實時合成，無取樣——帶 rock、house 和 hip-hop 預設和速度控制，完全免費。

您曾經跟隨的每一個節拍都是網格上擊打的模式。這個音序器為您提供那個網格：十六步（一小節十六分音符），四種由純合成製成的經典鼓聲——用於 kick 的音高下降正弦波、用於 snare 和踩鑔的濾波噪聲——以及顯示 rock、house 和 hip-hop 如何不同地放置其擊打的預設。

第 1、5、9 和 13 步是小節的四個主節拍——大多數 kick 和 snare 模式都圍繞它們構建。所有四種聲音（kick、snare、閉合 hi-hat、開口 hi-hat）都在您的瀏覽器中實時合成；沒有音訊取樣，也沒有下載任何東西。

設計上的隱私： 鼓音序器使用 Web Audio API 在您的瀏覽器中本地合成每種聲音。沒有要下載的取樣，沒有麥克風，也沒有上傳任何東西——關閉選項卡，一切都消失了。

如何使用此工具

  1. 選擇一個預設來聽一個完成的模式，或開始在網格上點選步進——每行是一種鼓聲，每列是一個十六分音符步進。
  2. 按“播放”。當前步進在小節迴圈時以金色勾勒。
  3. 在播放時更改步進、速度和音量——變化在迴圈到達它們時應用。
  4. 使用“清除網格”從靜音開始，並從四個主節拍（第 1、5、9、13 步）向外構建您自己的模式。

常見問題

鼓音序器免費嗎？

是的。它完全免費，無需註冊，我們沒有強加限制。

鼓聲是取樣嗎？

不會——每種聲音都是實時合成的。Kick 是一個正弦波，其音高在十分之一秒內從 150 Hz 降至約 42 Hz（經典的電子 kick 配方）；snare 是帶通濾波噪聲加一個短音調；hi-hat 是高通噪聲，閉合的短，開口的長。這就是為什麼頁面即刻載入，無需下載任何東西。

16 步是什麼意思？

一小節分為十六分音符。在 120 BPM 時，每步正好是 0.125 秒，因此第 1、5、9 和 13 步落在小節的四個主節拍上。

為什麼模式一直迴圈？

步進音序器按設計就是一臺迴圈機器——一小節重複播放，以便您可以構建和評判一種律動。更改任何內容，您都會在下一輪聽到變化。

我可以儲存或下載我的節奏嗎？

不是從此頁面——它是一個用於演奏和學習模式的現場樂器。要錄製節奏，播放它並使用本站的螢幕錄影機帶聲音捕獲它，或記下網格：這裡的每個預設和模式都只是 64 個開關步進。

工作原理

網格儲存為四行十六個開關步進——正是頁面與其經過測試的模式引擎共享的模式格式，該引擎將模式擴充套件為定時的事件（在 120 BPM 時，第 8 步正好在 1.0 秒）。播放使用 Web Audio 時鐘上的前視排程器：聲音被合成並放置在時間稍前方，因此即使螢幕繁忙，律動也保持緊湊。

四種聲音是合成配方，而不是錄音。那使頁面保持零下載、零取樣，並且在每臺裝置上聲音相同。

實際示例

一位音樂老師想讓她的班級在沒有任何裝置的情況下聽到不同音樂流派的差異。她以相同的速度載入 Rock（kick 在 1 和 9，snare 在 5 和 13），然後是 House（每個節拍都有 kick），然後是節奏更密集的 Hip-Hop——三個網格，三種律動，全班可以確切地看到和聽到發生了什麼變化。

更多問題

為什麼沒有低音線或旋律？

此工具僅是鼓機——節奏優先。旋律樂器將是單獨的工具；將此頁面保持為四種鼓聲使它即時且易於學習。

節拍在非常高或非常低的音量下聽起來不同——為什麼？

小型揚聲器無法忠實再現 kick 的基頻（約 42-150 Hz），因此 kick 在手機揚聲器上聽起來比在耳機上薄。這是物理，不是模式的錯誤。

我可以製作奇數拍號嗎？

網格是一小節 16 個十六分步進。使一行最後的步進留空僅在所有行都同意時才建立更短的迴圈——對於真正的奇數拍子，本站的節拍器直接涵蓋每小節的拍數。
