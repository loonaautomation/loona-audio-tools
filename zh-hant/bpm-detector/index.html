BPM 檢測器 - 免費線上查詢歌曲的速度

簡而言之： BPM 檢測器以每分鐘節拍數查詢歌曲或錄音的速度，顯示檢測的可信度，並誠實地告訴您檔案何時根本沒有清晰的節拍——完全免費，您的檔案從不離開您的裝置。

正在排隊兩首曲目的 DJ、為活動選擇合適節奏音樂的教師、數著節拍的舞者和編輯——他們都從一個數字開始：BPM。載入一個檔案，此工具將測量最強的重複節拍，用通俗的語言顯示其可信度，併為您提供一個拍速按鈕，用您自己的耳朵檢查答案。

如何使用此工具

  1. 點選上方框或將您的音訊檔案拖入其中——MP3、WAV、M4A 和 OGG 都可以。分析自動開始；10 秒或更長的檔案給出最可靠的結果。
  2. 閱讀檢測到的速度、可信度說明、每拍秒數，以及檔案中估計的節拍數。
  3. 如果音符顯示未找到清晰的節拍，請相信它——語音和環境錄音通常沒有穩定的速度，顯示的數字只是最強的模式。
  4. 可選檢查：播放曲目並在每個節拍上點選“在節拍上點選”按鈕，將您自己的速度與檢測器進行比較。

常見問題

BPM 檢測器免費嗎？

是的。它完全免費，無需註冊，我們沒有強加限制。

我的音訊檔案會上傳到伺服器嗎？

不會。您的檔案使用 Web Audio API 100% 在您的瀏覽器內解碼和分析。它從不離開您的裝置。

檢測有多準確？

在節拍清晰、穩定的音樂上——鼓曲目、流行、電子音樂、節拍器般的錄音——使用從 60 到 174 BPM 的已知速度的受控測試被準確檢測。在複雜的真實音樂上，最強的模式偶爾可能是您感覺到的速度的一半或兩倍，這就是為什麼頁面顯示可信度評級幷包括拍速檢查。

可信度數字是什麼意思？

它將獲勝節拍模式的強度與所有速度下的平均模式強度進行比較。節拍清晰的曲目得分 5 或更高；頁面將 2.5 及以上的結果稱為清晰節拍。穩定的音調或語音得分約 1——沒有真正的節拍。

它可以檢測哪些速度？

在 40 和 208 BPM 之間，以半 BPM 為步進。幾乎所有歌曲，從慢速抒情曲到快速電子曲目，都落在這個範圍內。

工作原理

您的檔案在您的瀏覽器內開啟，並使用 Web Audio API 解碼為原始聲音取樣——不上傳到任何伺服器。工具構建一個起始包絡：一條曲線，顯示聲音能量如何逐刻急劇上升，在鼓擊、音符起始或其他節拍事件發生的任何地方都會出現峰值。然後它以從 40 到 208 BPM 的每個速度（速度圖）測量該曲線，並報告其節奏與峰值最強烈匹配的速度。

可信度評級是答案的一部分，而不是裝飾：當沒有速度突出時——如語音、穩定的音調，或自由時間的音樂——工具會直白地說出來，而不是編造一個數字。

實際示例

一位舞蹈老師想讓課堂音樂約為 120 BPM。她將三首候選歌曲逐一放入檢測器：第一首讀數為 122 BPM，節拍清晰；第二首為 96 BPM；第三首是一段採訪錄音，誠實地報告沒有清晰的節拍。她選擇了第一首歌，每拍秒數 0.492，並據此規劃她的編舞。

更多問題

為什麼它報告的速度是我預期的兩倍（或一半）？

一些節奏在兩個層級上同時強烈重複——例如一首同時有慢 kick 和快踩鑔模式的曲目。檢測器報告整體模式最強的層級。頁面上的拍速工具讓您確認您感覺到的層級。

它可以檢測現場表演的速度嗎？

先將表演儲存或錄製為檔案——本站的錄音機可以做到這一點——然後在此處載入檔案。檢測器需要一份完成的錄音來分析。

為什麼我的語音錄音會顯示 BPM？

它顯示它能找到的最強的重複模式，標記為低可信度，並有明確的“未找到清晰節拍”說明。對於語音，將該數字視為無意義——誠實的讀數是可信度說明，而不是數字。
