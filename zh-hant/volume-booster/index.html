常見問題

音量增強器免費嗎？

是的。它完全免費，無需註冊，沒有水印，我們沒有強加限制。

我的音訊檔案會上傳到伺服器嗎？

不會。您的檔案使用 Web Audio API 100% 在您的瀏覽器內解碼和放大。它從不離開您的裝置。

什麼是削波，為什麼有警告？

數字音訊的最大電平為 100%。如果增強將取樣推過該限制，它們會被平直地切掉——那就是削波，聽起來像刺耳的失真。每當您選擇的增強會將最響的峰值推過 100% 時，警告就會出現，這樣您可以在它發生之前降低增強或使用歸一化。

歸一化做什麼？

歸一化測量整個檔案中最響的時刻，並縮放一切，使該峰值正好落在 100%——檔案在沒有任何削波的情況下可以達到的最響。帶有一個響亮時刻的安靜錄音不會獲得多少；均勻安靜的錄音會獲得很多。

300% 是多少分貝？

300% 音量約為 +9.5 dB。200% 約為 +6 dB，50% 約為 -6 dB。拖動時，工具會在滑塊旁邊顯示確切的 dB 值。

工作原理

您的檔案在您的瀏覽器內開啟，並使用 Web Audio API 解碼為原始聲音取樣——不上傳到任何伺服器。工具測量檔案中的最高取樣（其峰值），在離線渲染中將每個取樣乘以您選擇的增益，如果結果將超過 100% 數字上限則警告您，並將結果儲存為 WAV 檔案。

實際示例

您在手機上錄製了一次採訪，最響的時刻僅達到最大電平的 30%。您載入檔案，並不猜測滑塊值，而是勾選“改為歸一化”。整個採訪被放大了約 3.3 倍，使其峰值正好達到 100%——每個詞現在都儘可能地響亮且安全，沒有失真，您下載 WAV。

增強和歸一化都會在提高聲音的同時提高噪聲，因此請從您擁有的最乾淨的錄音開始。

更多問題

增強會去除背景噪聲嗎？

不會——增強會將一切一起變響，包括原始錄音中的任何嘶嘶聲或房間噪聲。它不能清潔音訊，只能提高其電平。

為什麼下載的檔案比我的 MP3 大？

匯出是 WAV，您的瀏覽器可以原生建立的未壓縮格式。它保持音訊正如渲染後的樣子，但檔案比 MP3 大。任何標準轉換器之後都可以將 WAV 變成 MP3。

我的錄音在一個地方響亮，在其他地方安靜。我該怎麼辦？

那是一個動態問題，而不是普通的音量問題。歸一化只會有一點幫助，因為那個響亮的時刻設定了限制。用音訊剪下器剪掉或單獨增強安靜的部分通常效果更好。
