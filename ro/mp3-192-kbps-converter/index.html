Despre acest instrument

La 192 kbps, un MP3 este alegerea echilibrată implicită — muzica sună plin, fișierele rămân mici și aproape niciun ascultător nu îl poate deosebi de original. Rata de biți este numărul de biți pe secundă pe care codorul are voie să îi folosească: mai mare înseamnă mai multe detalii păstrate și un fișier mai mare — aproximativ 192 de kilobiți pe secundă, adică circa 1.4 MB pe minut.

Această pagină codează cu codorul MP3 lamejs (același motor din spatele Convertorului audio principal), rulând în întregime în browserul tău. Intrarea este decodată de Web Audio API, așa că formatele pe care browserul tău le poate decoda sunt formatele din care poți converti.

Exemplu rezolvat

Un podcaster convertește un interviu de 45 de minute în MP3 la 192 kbps. Fișierul are aproximativ 63 MB — suficient de mic pentru găzduire și redare în flux, iar vocile sună clar.

Întrebări frecvente

Calitatea se va schimba?

Conversia în WAV este fără pierderi — eșantioanele decodate sunt scrise exact. Conversia în MP3 este cu pierderi: fișierul se micșorează, dar unele detalii sunt aruncate definitiv. Conversia MP3 în WAV nu restaurează calitatea pierdută; schimbă doar containerul.

Fișierul meu audio este privat?

Da. Decodarea și codarea se întâmplă 100% în browserul tău, cu Web Audio API și un codor MP3 local. Fișierul nu este încărcat, stocat sau auzit niciodată de noi.

Ce se întâmplă dacă browserul meu nu poate decoda fișierul?

Decodarea depinde de browserul tău: Chrome și Edge decodează cea mai largă gamă; Safari gestionează M4A/AAC nativ; Firefox nu decodează M4A/AAC. Dacă un fișier nu se decodează, încearcă alt browser.
