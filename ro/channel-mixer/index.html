Întrebări frecvente

Mixerul de canale este gratuit?

Da. Este complet gratuit, fără înregistrare, fără filigran și fără nicio limită impusă de noi.

Fișierele mele audio sunt încărcate pe un server?

Nu. Fișierul tău este decodat și convertit 100% în browserul tău, cu Web Audio API. Nu părăsește niciodată dispozitivul.

Cum funcționează Stereo în Mono?

Fiecare pereche de eșantioane stâng și drept este mediată într-un singur eșantion. Rezultatul se redă identic în ambele urechi. Sunetele care există doar ca diferență între canale pot deveni mai silențioase - aceasta este o proprietate a stereoului însuși, explicată onest în textul de ajutor de pe pagină.

Mono în Stereo face sunetul mai bogat?

Nu - copiază același semnal pe ambele canale, așa că fișierul devine un fișier stereo corespunzător, care se redă centrat în ambele urechi, dar nu se creează nicio informație stereo nouă. Exact asta au nevoie majoritatea playerelor și formularelor de încărcare.

Înregistrarea mea se redă doar într-o ureche. Ce opțiune rezolvă?

Doar canalul stâng dacă sunetul este în urechea stângă sau Doar canalul drept dacă este în urechea dreaptă. Canalul funcțional este copiat pe ambele părți, așa că înregistrarea se redă centrată în ambele urechi.

Cum funcționează

Fișierul tău este deschis direct în browserul tău și decodat în fluxuri separate de eșantioane stâng și drept, cu Web Audio API - nimic nu este încărcat pe niciun server. Fiecare conversie este matematică simplă și exactă a eșantioanelor: mono mediază canalele eșantion cu eșantion, stereo duplică, schimbarea le interschimbă, iar modurile unilaterale copiază canalul ales peste celălalt. Rezultatul este scris ca fișier WAV standard, la rata de eșantionare originală.

Pentru că matematica este exactă, nimic nu este recomprimat și nimic nu este ghicit: ceea ce auzi în previzualizare este exact ceea ce conține fișierul descărcat.

Exemplu rezolvat

O profesoară înregistrează un interviu cu un microfon stereo, dar invitatul a stat pe partea pe care cablul defect o amuțise - invitatul se aude doar în urechea stângă. Alege Doar canalul stâng, iar WAV-ul descărcat redă invitatul centrat în ambele urechi, gata de împărtășit cu clasa ei.

Mai multe întrebări

Pot separa o melodie stereo înapoi în voci și instrumente?

Nu - aceasta nu este o operațiune de canal. Odată ce sunetele sunt amestecate în două canale, instrumentele de canale pot doar amesteca, copia sau schimba acele canale între ele, nu pot dezamesteca sunetele originale.

Ce se întâmplă când schimb canalele pe un fișier mono?

Nimic nu se schimbă - există un singur canal, așa că nu este nimic de schimbat. Instrumentul trece fișierul neschimbat, ca WAV mono.

De ce descărcarea iese ca WAV?

WAV este formatul pe care browserul tău îl poate crea nativ, fără software suplimentar, și păstrează canalele convertite exact așa cum au fost calculate. Folosește Convertorul audio dacă ai nevoie de MP3 după aceea.
