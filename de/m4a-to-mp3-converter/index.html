Über dieses Tool

M4A-Dateien laufen auf Apple-Geräten und fast nirgendwo sonst zuverlässig. MP3 ist die universelle Antwort: Ein iPhone-Sprachmemo oder eine heruntergeladene M4A mit 192 kbps in MP3 zu konvertieren macht sie auf Android, Windows, Autoradios und im Web abspielbar.

Derselbe Browser-Vorbehalt gilt: Safari und Chrome dekodieren M4A; Firefox nicht. Die Konvertierung selbst ist ein standardmäßiger verlustbehafteter Schritt — die MP3 wird wie die M4A klingen, bei einem Zehntel der Größe.

Durchgerechnetes Beispiel

Ein Vater erhält das Lied seiner Tochter als M4A von ihrem iPhone. In MP3 konvertiert, wird es auf den Android-Telefonen der Familie und im Autoradio auf der Heimfahrt abgespielt.

Häufig gestellte Fragen

Ändert sich die Qualität?

Die Konvertierung in WAV ist verlustfrei — die dekodierten Samples werden exakt herausgeschrieben. Die Konvertierung in MP3 ist verlustbehaftet: Die Datei schrumpft, aber einige Details werden dauerhaft verworfen. MP3 in WAV zu konvertieren stellt verlorene Qualität nicht wieder her; es ändert nur den Container.

Ist meine Audiodatei privat?

Ja. Dekodierung und Kodierung geschehen zu 100% in Ihrem Browser mit der Web Audio API und einem lokalen MP3-Encoder. Die Datei wird niemals hochgeladen, gespeichert oder von uns gehört.

Was, wenn mein Browser die Datei nicht dekodieren kann?

Die Dekodierung hängt von Ihrem Browser ab: Chrome und Edge dekodieren die größte Auswahl; Safari verarbeitet M4A/AAC nativ; Firefox dekodiert M4A/AAC nicht. Wenn eine Datei nicht dekodiert wird, versuchen Sie einen anderen Browser.
