Wie Loona Audio Tools funktionieren

  1. Wählen Sie ein Tool und fügen Sie Ihr Audio hinzu. Ihre Datei wird von Ihrem eigenen Browser gelesen - nichts wird irgendwohin gesendet. Der Sprachrekorder bittet nur um die Mikrofonberechtigung, wenn Sie auf Aufnehmen drücken.
  2. Schneiden, verbinden oder aufnehmen. Ziehen Sie die Griffe der Wellenform, ordnen Sie Ihre Dateien oder sprechen Sie - alles geschieht auf Ihrem Gerät.
  3. Laden Sie das Ergebnis herunter. Das fertige Audio wird auf Ihrem Gerät erstellt und lädt sofort herunter.

Warum Menschen browserbasierten Tools vertrauen

Die meisten Online-Audio-Seiten verlangen, dass Sie Ihre Lieder, Vorlesungen und Sprachaufnahmen auf den Server eines Fremden hochladen. Häufig gestellte Fragen

Sind Loona Audio Tools wirklich kostenlos?

Ja - jedes Tool ist zu 100% kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne von uns auferlegte Tageslimits.

Werden meine Audiodateien auf Ihren Server hochgeladen?

Niemals. Jedes Tool läuft zu 100% in Ihrem Browser mit der darin eingebauten Web-Audio-Technologie. Ihre Dateien und Aufnahmen bleiben von Anfang bis Ende auf Ihrem Gerät.

Welche Audioformate kann ich verwenden?

Der Cutter und der Joiner akzeptieren die Formate, die Ihr Browser dekodieren kann - MP3, WAV, M4A und OGG in allen modernen Browsern. Exportierte Dateien sind Standard-WAV, die überall spielt.

Sendet der Sprachrekorder meine Stimme irgendwohin?

Nein. Der Rekorder läuft vollständig auf Ihrem Gerät. Ihr Mikrofon wird nur eingeschaltet, wenn Sie auf Aufnehmen drücken, und die Aufnahme wird nur gespeichert, wenn Sie sie herunterladen.

Welche Geräte werden unterstützt?

Jeder moderne Browser auf Telefon, Tablet oder Computer - Chrome, Edge, Firefox und Safari funktionieren alle. Der Sprachrekorder benötigt ein Mikrofon und die Erlaubnis, es zu verwenden.
