Audio-Tempoänderer - Audio online kostenlos beschleunigen oder verlangsamen

Kurz gesagt: der Audio-Tempoänderer spielt jede Audiodatei schneller oder langsamer ab - von 0.25x bis 3x - völlig kostenlos, und Ihre Datei verlässt niemals Ihr Gerät. Ein ehrlicher Hinweis: Das Ändern der Geschwindigkeit ändert auch die Tonhöhe, wie beim Beschleunigen einer Schallplatte.

Eine Vorlesung, die sich zieht, ein Podcast, den Sie schneller zu Ende hören möchten, ein Gitarrenriff, das Sie zum Lernen verlangsamen müssen - dieses Tool ändert das Tempo jeder Audiodatei. Bewegen Sie den Schieberegler, hören Sie das Ergebnis sofort in der neuen Geschwindigkeit und laden Sie es als WAV-Datei herunter.

So ändern Sie die Geschwindigkeit einer Audiodatei

  1. Klicken Sie auf das Feld oben oder ziehen Sie Ihre Audiodatei hinein - MP3, WAV, M4A und OGG funktionieren alle.
  2. Bewegen Sie den Geschwindigkeitsregler (oder geben Sie einen exakten Wert ein) zwischen 0.25x und 3x. Die neue Dauer aktualisiert sich beim Ziehen.
  3. Drücken Sie auf „Mit dieser Geschwindigkeit abspielen“, um das Ergebnis zu hören - Stimmen klingen bei schnelleren Geschwindigkeiten höher und bei langsameren tiefer.
  4. Klicken Sie auf „WAV mit dieser Geschwindigkeit herunterladen“, und das neu gerenderte Audio wird auf Ihrem Gerät gespeichert.

Häufig gestellte Fragen

Ist der Audio-Tempoänderer kostenlos?

Ja. Es ist völlig kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne von uns auferlegte Grenze, wie viele Dateien Sie verarbeiten.

Werden meine Audiodateien auf einen Server hochgeladen?

Nein. Ihre Datei wird zu 100% in Ihrem Browser mit der Web Audio API dekodiert und neu gerendert. Sie verlässt niemals Ihr Gerät.

Ändert das Ändern der Geschwindigkeit die Tonhöhe?

Ja - ehrlich, das tut es. Dieses Tool funktioniert wie das Beschleunigen oder Verlangsamen einer Schallplatte: Mit 2x Geschwindigkeit klingen Stimmen höher und kleiner, mit 0.5x klingen sie tiefer und dunkler. Wenn Sie das Tempo bei gleichbleibender Tonhöhe geändert brauchen, erfordert das eine andere Technik (Time-Stretching), die dieses einfache Tool nicht ausführt.

Welche Formate kann ich verwenden?

Jedes Format, das Ihr Browser dekodieren kann - MP3, WAV, M4A und OGG in allen modernen Browsern. Das Ergebnis wird als Standard-WAV-Datei heruntergeladen, die überall abgespielt wird.

Wie stark kann ich die Geschwindigkeit ändern?

Von 0.25x (viermal langsamer) bis 3x (dreimal schneller). Ein 4-minütiges Lied wird mit 3x zu 1 Minute 20 Sekunden oder mit 0.25x zu 16 Minuten.

So funktioniert es

Ihre Datei wird direkt in Ihrem Browser geöffnet und mit der Web Audio API in rohe Sound-Samples dekodiert - nichts wird auf einen Server hochgeladen. Beim Export werden die Samples mit Ihrer gewählten Wiedergaberate in einen Offline-Renderer abgespielt, was eine kürzere oder längere Aufnahme erzeugt, und dieses Ergebnis wird als WAV-Datei gespeichert.

Durchgerechnetes Beispiel

Sie haben eine 60-minütige aufgezeichnete Vorlesung und eine einstündige Fahrt. Sie laden die Datei, stellen die Geschwindigkeit auf 1.5x, und die neue Dauer zeigt 40 Minuten. Sie hören ein paar Sekunden zur Vorschau, um zu prüfen, ob die Stimme noch leicht zu verfolgen ist, und laden dann die WAV herunter - die ganze Vorlesung passt jetzt in 40 Minuten Hören.

Weil Geschwindigkeit und Tonhöhe bei dieser Methode verknüpft sind, klingt eine Stimme mit 2x deutlich höher. Bei Vorlesungen, Podcasts und Übungsaudio ist das meist ein fairer Kompromiss; bei Musik bevorzugen Sie vielleicht kleinere Änderungen wie 1.1x oder 0.9x.

Weitere Fragen

Warum ist die heruntergeladene Datei größer als meine MP3?

Der Export ist WAV, das unkomprimierte Format, das Ihr Browser nativ erstellen kann. WAV behält das Audio genau so, wie es gerendert wurde, aber die Dateien sind größer als MP3. Jeder Standard-Konverter kann die WAV danach in MP3 verwandeln, wenn Sie sie kleiner brauchen.

Kann ich eine sehr lange Vorlesung beschleunigen?

Ja, aber sehr lange Dateien hängen vom Speicher Ihres Geräts ab, weil die ganze Datei im Browser dekodiert und neu gerendert wird. Die meisten Vorlesungen, Lieder und Sprachnotizen funktionieren gut.

Welche Geschwindigkeit ist am besten zum Lernen?

Viele Studenten verwenden 1.25x-1.5x für Vorlesungen, die sie schon einmal gehört haben, und 0.75x für schwierige Passagen oder zum Sprachenlernen. Es gibt keine Regel - verwenden Sie, was Ihre Ohren bequem verfolgen können.
