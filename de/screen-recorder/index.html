Bildschirmrekorder - Nehmen Sie Ihren Bildschirm online kostenlos auf

Kurz gesagt: der Bildschirmrekorder erfasst Ihren Bildschirm, einen Browser-Tab oder ein einzelnes Fenster - völlig kostenlos, nichts wird hochgeladen, und das Video wird als WebM-Datei heruntergeladen.

Einen Fehler zu erklären, eine Lektion zu unterrichten oder jemandem zu zeigen, wie eine Website funktioniert, ist mit einem kurzen Video viel einfacher als mit zehn Screenshots. Drücken Sie auf Start, wählen Sie, was Sie teilen möchten, tun Sie Ihr Ding und laden Sie die Aufnahme herunter. Ihr Mikrofon kann eingemischt werden, wenn Sie kommentieren möchten.

Aufnahme herunterladen
Privat durch Design: die Bildschirmaufnahme geschieht vollständig in Ihrem Browser. Die Aufnahme wird im Speicher Ihres Browsers gehalten, während Sie aufnehmen, und nur gespeichert, wenn Sie auf Herunterladen klicken. Nichts wird auf einen Server hochgeladen, und das Schließen des Tabs löscht alles.

So nehmen Sie Ihren Bildschirm auf

  1. Kreuzen Sie „Mikrofon-Audio“ an, wenn Sie kommentieren möchten, und „System- / Tab-Audio“, wenn der Klang eines Tabs aufgezeichnet werden soll (Chrome oder Edge auf dem Desktop).
  2. Klicken Sie auf „Aufnahme starten“ und wählen Sie in der Auswahl des Browsers, was Sie teilen möchten: einen Browser-Tab, ein Fenster oder Ihren gesamten Bildschirm.
  3. Tun Sie, was Sie zeigen möchten - der Timer oben zeigt, wie lange Sie schon aufnehmen. Dieser Tab bleibt im Hintergrund der Aufnahme und nicht in ihr, es sei denn, Sie teilen den gesamten Bildschirm.
  4. Klicken Sie auf „Aufnahme stoppen“ (oder auf die eigene Leiste „Freigabe beenden“ des Browsers). Sehen Sie sich die Vorschau an und klicken Sie dann auf „Aufnahme herunterladen“, um die WebM-Datei zu speichern.

Häufig gestellte Fragen

Ist der Bildschirmrekorder kostenlos?

Ja. Es ist völlig kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne von uns auferlegtes Aufnahmelimit.

Wird meine Bildschirmaufnahme auf einen Server hochgeladen?

Nein. Die Aufnahme wird während des Aufnehmens vollständig in Ihrem Browser erfasst und gespeichert, und die fertige Datei wird auf Ihrem Gerät erstellt, wenn Sie sie herunterladen. Nichts wird jemals hochgeladen.

Als welches Format wird die Aufnahme heruntergeladen?

WebM in Chrome, Edge und Firefox (MP4 in neueren Safari-Versionen). WebM läuft in allen modernen Browsern und lädt direkt auf YouTube und die meisten anderen Plattformen hoch.

Kann ich neben meiner Stimme auch Ton von meinem Computer aufnehmen?

Ihre Stimme: Ja - kreuzen Sie „Mikrofon-Audio“ an und erlauben Sie den Mikrofonzugriff. Klang, der vom Computer selbst kommt (System-/Tab-Audio), funktioniert nur in Chrome und Edge auf dem Desktop, und nur, wenn Sie einen Browser-Tab teilen und die Option zum Teilen des Audios in der Auswahl ankreuzen. Andere Browser können System-Audio nicht erfassen - das ist eine Browsergrenze, nichts, was eine Website ändern könnte.

Welche Browser unterstützen Bildschirmaufnahme?

Chrome, Edge und Firefox auf dem Desktop unterstützen es vollständig. Safari unterstützt es ab Version 14.1 auf macOS. Auf Telefonen erlauben die meisten mobilen Browser Websites nicht, den Bildschirm aufzunehmen - verwenden Sie für dieses Tool einen Desktop-Browser.

So funktioniert es

Wenn Sie auf Start drücken, zeigt die eingebaute Bildschirmaufnahme-Funktion Ihres Browsers (getDisplayMedia) ihre eigene Auswahl und übergibt dieser Seite einen Live-Videostream von genau dem, was Sie gewählt haben - nicht mehr. Die Seite zeichnet diesen Stream auf der Stelle mit dem MediaRecorder des Browsers auf. Das fertige Video wird im Speicher Ihres Browsers zusammengesetzt und als Download angeboten; kein Server sieht jemals ein einziges Bild.

Durchgerechnetes Beispiel

Sie möchten einem Schüler zeigen, wie man ein Formular auf einem Schulportal einreicht. Sie kreuzen „Mikrofon-Audio“ an, klicken auf Start, wählen den Browser-Tab mit dem Portal, füllen das Formular langsam aus, während Sie jeden Schritt laut erklären, und stoppen die Aufnahme nach 1 Minute 40 Sekunden. Sie sehen sich das Video in der Vorschau an, laden die WebM-Datei herunter und senden sie - Gesamtkosten null, und die Daten des Schülers haben niemals einen Server berührt.

Weil der Browser selbst die Auswahl und die Leiste „Freigabe beenden“ steuert, haben Sie immer die Kontrolle: Die Aufnahme kann nur das enthalten, was Sie ausgewählt haben, und sie endet in dem Moment, in dem Sie es sagen.

Weitere Fragen

Warum bot die Auswahl kein Audio an?

System-Audio wird nur in Chrome und Edge auf dem Desktop angeboten, und nur für Browser-Tabs - Fenster und Vollbild sind in diesen Browsern immer stumm. Ihr Mikrofon funktioniert stattdessen in jedem unterstützten Browser über das Ankreuzfeld „Mikrofon-Audio“.

Meine Aufnahme hat keinen Ton - was ist schiefgegangen?

Prüfen Sie drei Dinge: Das Kästchen „Mikrofon-Audio“ war angekreuzt und die Erlaubnis erteilt; für Tab-Ton war der Schalter „Tab-Audio teilen“ in der Auswahl eingeschaltet; und der Tab hat während der Aufnahme tatsächlich Ton abgespielt. Stille Quellen werden als Stille aufgenommen.

Wie lange kann ich aufnehmen?

Es gibt von uns keine Grenze, aber die Aufnahme wird im Speicher Ihres Browsers gehalten, bis Sie sie herunterladen. Sehr langen Aufnahmen (Stunden) kann auf kleineren Geräten der Speicher ausgehen - nehmen Sie bei langen Sitzungen in Teilen auf.

Was, wenn ich statt der Stopp-Schaltfläche auf „Freigabe beenden“ des Browsers drücke?

Das funktioniert auch. Die Aufnahme endet, und Ihre Vorschau und Ihr Download erscheinen, genau als hätten Sie die Stopp-Schaltfläche auf dieser Seite verwendet.
