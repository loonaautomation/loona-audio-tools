Sprachrekorder - Nehmen Sie Ihre Stimme online kostenlos auf

Kurz gesagt: der Sprachrekorder nimmt Ihre Stimme direkt von Ihrem Mikrofon auf, vollständig auf Ihrem Gerät - kostenlos, privat, und nichts wird jemals hochgeladen.

Eine schnelle Sprachnotiz, eine Unterrichtserklärung für Ihre Klasse, eine Übungsaufnahme für ein Lied oder eine Nachricht in Ihren eigenen Worten - drücken Sie auf Aufnehmen, sprechen Sie und laden Sie Ihre Aufnahme herunter. Ihr Mikrofon ist nur während der Aufnahme eingeschaltet, und die Aufnahme bleibt auf Ihrem Gerät, bis Sie sie speichern.

0:00.0

Drücken Sie auf Aufnehmen, wenn Sie bereit sind. Ihr Browser wird nach der Mikrofonberechtigung fragen - sie wird nur angefragt, wenn Sie die Schaltfläche drücken.

Privat durch Design: Ihre Aufnahme wird zu 100% auf Ihrem Gerät gemacht und aufbewahrt. Das Mikrofon wird nur angefragt, wenn Sie auf Aufnehmen drücken, es wird in dem Moment ausgeschaltet, in dem Sie auf Stopp drücken, und Ihre Stimme wird niemals auf einen Server hochgeladen, niemals von uns gespeichert und niemals von uns gehört.

So nehmen Sie Ihre Stimme auf

  1. Drücken Sie die Aufnahmeschaltfläche oben - Ihr Browser wird nach der Mikrofonberechtigung fragen, erlauben Sie sie also.
  2. Sprechen Sie normal; der Timer zeigt, wie lange Sie schon aufnehmen. Sie können pausieren und fortsetzen, wenn Sie eine Pause brauchen.
  3. Drücken Sie auf Stopp und hören Sie dann mit dem erscheinenden Player zurück.
  4. Laden Sie die Aufnahme herunter, um sie zu behalten - oder löschen Sie sie und nehmen Sie eine neue Aufnahme auf.

Häufig gestellte Fragen

Ist der Sprachrekorder kostenlos?

Ja. Es ist völlig kostenlos, ohne Anmeldung und ohne von uns auferlegtes Aufnahmelimit.

Wird meine Aufnahme irgendwo hochgeladen?

Nein. Ihre Stimme wird nur im Speicher Ihres Browsers auf Ihrem eigenen Gerät aufgezeichnet und aufbewahrt. Sie wird nur gespeichert, wenn Sie die Download-Schaltfläche drücken - nichts wird jemals an einen Server gesendet.

Wann ist mein Mikrofon eingeschaltet?

Nur nachdem Sie auf Aufnehmen drücken und die Erlaubnis geben. In dem Moment, in dem Sie auf Stopp drücken, wird das Mikrofon wieder ausgeschaltet.

Welches Format hat die Aufnahme?

Ihr Browser nimmt in seinem Standard-Web-Audioformat auf (normalerweise WebM). Es spielt in allen modernen Browsern und Apps und kann mit dem Audio-Cutter oder jedem Konverter in MP3 oder WAV konvertiert werden.

Was passiert, wenn ich den Tab vor dem Herunterladen schließe?

Die Aufnahme geht verloren, weil sie nur im Speicher des Tabs existiert. Laden Sie Ihre Aufnahme immer herunter, bevor Sie die Seite schließen.

So funktioniert es

Wenn Sie auf Aufnehmen drücken, bittet die Seite Ihren Browser - nicht einen Server - um Zugriff auf Ihr Mikrofon. Ihr Browser erfasst Ihre Stimme mit seiner eingebauten MediaRecorder-Technologie und behält den Klang nur im Speicher dieses Tabs. Auf Stopp zu drücken schaltet das Mikrofon sofort aus und verwandelt den erfassten Klang in eine abspielbare Aufnahme, immer noch vollständig auf Ihrem Gerät.

Durchgerechnetes Beispiel

Eine Lehrerin möchte ihrer Klasse eine kurze gesprochene Erklärung der morgigen Lektion senden. Sie öffnet diese Seite auf ihrem Telefon, drückt auf Aufnehmen, spricht etwa eine Minute, drückt auf Stopp, hört einmal zur Kontrolle hinein und lädt die Datei herunter, um sie mit ihren Schülern zu teilen - ohne eine App zu installieren und ohne dass ihre Stimme jemals über den Server eines anderen läuft.

Weil nichts hochgeladen wird, funktioniert die Aufnahme selbst bei einer langsamen Verbindung, und es gibt kein Konto, kein Postfach und keinen Cloud-Ordner, in dem Ihre Stimme ohne Ihr Wissen aufbewahrt werden könnte.

Weitere Fragen

Warum ist das Mikrofon nicht gestartet?

Ihr Browser braucht die Mikrofonberechtigung für diese Seite. Prüfen Sie das Schloss- oder Einstellungssymbol in der Adressleiste, erlauben Sie das Mikrofon und drücken Sie dann erneut auf Aufnehmen. Auf manchen Telefonen erscheint die Berechtigungsabfrage nur beim ersten Mal.

Kann ich mir die Aufnahme anhören, bevor ich sie speichere?

Ja - sobald Sie auf Stopp drücken, erscheint ein Player mit Ihrer Aufnahme, sodass Sie zurückhören können, bevor Sie sich entscheiden, sie herunterzuladen oder zu löschen.

Wie lange kann ich aufnehmen?

Dieses Tool setzt keine Grenze. Sehr lange Aufnahmen verwenden mehr Speicher Ihres Geräts, also ist es bei Sitzungen von mehr als einer Stunde sicherer, in Teilen herunterzuladen.

Kann ich auf meinem Telefon aufnehmen?

Ja - jeder Telefonbrowser mit Mikrofonzugriff funktioniert. Lassen Sie den Tab offen und den Bildschirm während der Aufnahme an, um das beste Ergebnis zu erzielen.
