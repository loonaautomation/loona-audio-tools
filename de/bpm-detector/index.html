BPM-Detektor - Das Tempo eines Lieds online kostenlos finden

Kurz gesagt: der BPM-Detektor findet das Tempo eines Lieds oder einer Aufnahme in Schlägen pro Minute, zeigt, wie sicher die Erkennung ist, und sagt Ihnen ehrlich, wenn eine Datei gar keinen klaren Beat hat - völlig kostenlos, und Ihre Datei verlässt niemals Ihr Gerät.

DJs, die zwei Tracks aneinanderreihen, Lehrer, die Musik im richtigen Tempo für eine Aktivität auswählen, Tänzer und Editoren, die Schläge zählen - sie alle beginnen mit einer Zahl: BPM. Laden Sie eine Datei, und dieses Tool misst den stärksten sich wiederholenden Beat, zeigt seine Sicherheit in einfacher Sprache und gibt Ihnen eine Tap-Tempo-Schaltfläche, um das Ergebnis mit Ihren eigenen Ohren zu prüfen.

Häufig gestellte Fragen

Ist der BPM-Detektor kostenlos?

Ja. Es ist völlig kostenlos, ohne Anmeldung und ohne von uns auferlegte Grenze.

Werden meine Audiodateien auf einen Server hochgeladen?

Nein. Ihre Datei wird zu 100% in Ihrem Browser mit der Web Audio API dekodiert und analysiert. Sie verlässt niemals Ihr Gerät.

Wie genau ist die Erkennung?

Bei Musik mit einem klaren, gleichmäßigen Beat - Drum-Tracks, Pop, elektronische Musik, metronomartige Aufnahmen - wurden in kontrollierten Tests bekannte Tempi von 60 bis 174 BPM exakt erkannt. Bei komplexer echter Musik kann das stärkste Muster gelegentlich die Hälfte oder das Doppelte des Tempos sein, das Sie fühlen, weshalb die Seite eine Sicherheitsbewertung zeigt und eine Tap-Tempo-Prüfung enthält.

Was bedeutet die Sicherheitszahl?

Es vergleicht die Stärke des gewinnenden Beat-Musters mit der durchschnittlichen Musterstärke über alle Tempi. Tracks mit klarem Beat erreichen 5 oder mehr; die Seite bezeichnet ein Ergebnis ab 2.5 aufwärts als klaren Beat. Ein gleichmäßiger Ton oder Sprache erreicht etwa 1 - kein echter Beat.

Welche Tempi kann es erkennen?

Zwischen 40 und 208 BPM, in halben BPM-Schritten. Fast alle Lieder, von langsamen Balladen bis zu schnellen elektronischen Tracks, liegen in diesem Bereich.

So funktioniert es

Ihre Datei wird direkt in Ihrem Browser geöffnet und mit der Web Audio API in rohe Sound-Samples dekodiert - nichts wird auf einen Server hochgeladen. Das Tool erstellt eine Onset-Hüllkurve: eine Kurve, wie scharf die Klangenergie von Moment zu Moment ansteigt, die überall dort Spitzen zeigt, wo ein Drum-Schlag, ein Notenanschlag oder ein anderes Beat-Ereignis geschieht. Es misst diese Kurve dann bei jedem Tempo von 40 bis 208 BPM (ein Tempogramm) und meldet das Tempo, dessen Rhythmus am stärksten zu den Spitzen passt.

Die Sicherheitsbewertung ist Teil der Antwort, keine Dekoration: Wenn kein Tempo heraussticht - wie bei Sprache, einem gleichmäßigen Ton oder frei getimter Musik - sagt das Tool das offen, statt eine Zahl zu erfinden.

Durchgerechnetes Beispiel

Eine Tanzlehrerin möchte Unterrichtsmusik mit etwa 120 BPM. Sie legt nacheinander drei Kandidatenlieder in den Detektor: Das erste zeigt 122 BPM mit einem klaren Beat, das zweite 96 BPM, und das dritte ist eine Interviewaufnahme, die ehrlich meldet, dass kein klarer Beat erkennbar ist. Sie wählt das erste Lied, 0.492 Sekunden pro Schlag, und plant ihre Choreografie darauf.

Weitere Fragen

Warum meldete es das doppelte (oder halbe) Tempo, das ich erwartet hatte?

Manche Rhythmen wiederholen sich auf zwei Ebenen gleichzeitig stark - zum Beispiel ein Track mit einer langsamen Kick und einem schnellen Hi-Hat-Muster. Der Detektor meldet die Ebene, deren Muster insgesamt am stärksten ist. Das Tap-Tool auf der Seite lässt Sie die Ebene bestätigen, die Sie fühlen.

Kann es das Tempo einer Live-Aufführung erkennen?

Speichern oder nehmen Sie die Aufführung zuerst als Datei auf - der Sprachrekorder auf dieser Seite kann das - und laden Sie die Datei dann hier. Der Detektor braucht eine fertige Aufnahme zur Analyse.

Warum zeigt meine Sprachaufnahme überhaupt eine BPM?

Es zeigt das stärkste sich wiederholende Muster, das es finden konnte, gekennzeichnet mit niedriger Sicherheit und einem klaren Hinweis „kein klarer Beat“. Betrachten Sie diese Zahl bei Sprache als bedeutungslos - die ehrliche Aussage ist der Sicherheitshinweis, nicht die Zahl.
