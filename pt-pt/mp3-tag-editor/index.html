Editor de Tags MP3 - Veja & Edite Tags ID3 Online Grátis

Em resumo: o Editor de Tags MP3 lê a tag ID3 dentro do seu MP3 - título, artista, álbum, ano e capa - permite editá-los e salva um novo ficheiro cujo áudio é byte a byte idêntico, porque apenas o bloco de tags é reescrito e a música nunca é recodificada - totalmente grátis, e seu ficheiro nunca sai do seu dispositivo.

Títulos de músicas errados, artistas faltando, capas em branco na sua biblioteca de música - isso vive na tag ID3, um pequeno bloco de dados na frente de cada MP3. Esta ferramenta abre esse bloco com um leitor feito à mão, mostra o que há dentro e o reescreve de forma limpa como ID3v2.3: quadros que ela não gerencia (comentários, gêneros, dados personalizados) são preservados byte a byte, e os quadros de áudio são copiados intactos.

Perguntas Frequentes

O Editor de Tags MP3 é grátis?

Sim. É totalmente grátis, sem registo e sem limite imposto por nós.

Editar tags muda a qualidade do som?

Não - e esta é a promessa importante desta ferramenta: os quadros de áudio MP3 são copiados byte a byte. Apenas o bloco de tags ID3 na frente do ficheiro é reescrito. Os testes desta ferramenta provam que a parte de áudio de um ficheiro editado é idêntica ao original, byte a byte.

Quais versões e campos de tag são suportados?

A leitura oferece suporte a ID3v2.3 e ID3v2.4 (as versões que quase todos os MP3s usam), incluindo texto guardado como Latin-1, UTF-8 ou UTF-16, e ano guardado como TYER ou TDRC. A escrita sempre produz uma tag ID3v2.3 limpa. Os campos editáveis são título, artista, álbum e ano, além da capa.

O que acontece com quadros de tag que vocês não mostram, como comentários ou gênero?

Eles são preservados byte a byte e escritos de volta na nova tag. Apenas os quadros que este editor gerencia - os quatro campos de texto e a capa - são mudados.

Posso adicionar tags a um MP3 que não tem nenhuma?

Sim. Uma nova tag ID3v2.3 é criada e colocada na frente do áudio intacto.

Como funciona

Um ficheiro MP3 tem duas partes: um bloco de tags ID3v2 na frente (seu tamanho é guardado no cabeçalho do ficheiro como um número synchsafe especial), depois os quadros de áudio. O editor lê esse cabeçalho, percorre os quadros dentro da tag - TIT2 para título, TPE1 para artista, TALB para álbum, TYER/TDRC para ano, APIC para a imagem de capa - decodifica o texto deles na codificação que o ficheiro usou e mostra para você.

Ao guardar, ela constrói uma nova tag v2.3 a partir dos seus campos, reinsere a capa (mantida, substituída ou removida, como você escolheu), anexa cada outro quadro original inalterado e une o resultado aos bytes de áudio originais. Verificar se essa união é exata foi o coração dos testes: MP3s de teste com tags e capas plantadas foram lidos, editados e relidos, o áudio comparado byte a byte em cada etapa, e os ficheiros editados decodificados sem problemas por uma ferramenta de áudio externa.

Exemplo prático

Uma professora monta uma pequena biblioteca de MP3s de nasheed e aulas reunidos ao longo dos anos - metade mostra "Artista Desconhecido" e nenhuma capa no player. Uma noite com esta ferramenta: cada ficheiro recebe seu título, artista e ano reais, uma imagem de capa onde cabe uma, e o player finalmente mostra uma biblioteca organizada e nomeada - com cada gravação soando exatamente como antes, porque o áudio nunca foi tocado.

Mais perguntas

Minha imagem de capa é de outro formato - vai funcionar?

Capas PNG e JPEG são aceitas, o que cobre quase toda arte. Os bytes da imagem são guardados como estão, com o rótulo de tipo correto tirado do ficheiro que você escolher.

Por que meu ano mudou de formato depois de guardar?

O editor escreve o ano como um quadro TYER v2.3 usando os quatro primeiros caracteres que você digitar (por exemplo 1999). Se o ficheiro original usava uma data TDRC v2.4 como 1999-05-05, apenas a parte do ano é mantida - é o jeito v2.3 de guardá-la.

E se meu MP3 usar uma tag ID3v2.2 muito antiga?

O editor informa isso e escreve uma nova tag v2.3 com os valores que você inserir; v2.2 é rara e seus valores não são lidos. Ficheiros somente ID3v1 (a antiga tag de 128 bytes bem no fim) são tratados como MP3s sem tag e podem receber uma tag v2.3 adequada.
