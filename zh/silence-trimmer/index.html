常见问题

静音修剪器免费吗？

是的。它完全免费，无需注册，没有水印，我们没有强加限制。

我的音频文件会上传到服务器吗？

不会。您的文件使用 Web Audio API 100% 在您的浏览器内解码和修剪。它从不离开您的设备。

dB 阈值是什么意思？

它是声音算作静音的电平阈值。-40 dB（推荐用于语音）将任何低于全音量 1% 的声音视为静音。-60 dB 仅去除近乎完美的数字静音，而 -20 dB 是强力的，可能会吃掉安静的语音结尾。

我的第一个或最后一个词会被剪掉吗？

填充设置在两端保留额外的音频——默认 0.1 秒——因此自然的词开头和淡出得以保留。如果录音的开始非常柔和，请将填充提高到 0.3-0.5 秒。

它会去除文件中间的静音吗？

不会。此工具仅修剪开头和结尾。中间的停顿是录音的一部分，保持原样。

工作原理

您的文件在您的浏览器内打开，并使用 Web Audio API 解码为原始声音采样——不上传到任何服务器。工具从开头扫描，直到找到第一个比您的阈值更响的采样，并从结尾向后到最后一个响亮的采样。那两个点之外的一切都是被去除的静音；您选择的填充被添加回每一侧。

因为测量基于实际采样，所显示的数字——开头静音、结尾静音、保留秒数——对于您选择的阈值来说是精确的，而不是估计值。更改阈值，分析会立即更新，这样您可以在下载前看到权衡。

实际示例

您在手机上录制了一节 3 分钟的课程：您开始说话前有 4 秒的静音，结尾有 6 秒，当您去按停止按钮时。分析确切显示了这一点。使用 -40 dB 阈值和 0.1 秒的填充，您下载一个干净的 2 分钟 50 秒的 WAV，以您的声音开始和结束。

更多问题

为什么工具说我的整个文件是静音？

文件中的每个采样都低于所选阈值——要么录音确实是静音的或非常安静，要么阈值设置得太高。将阈值降至 -50 或 -60 dB，分析将再次运行。

我想也去除中间的停顿。怎么做？

使用音频剪切器将文件切成几部分，保留停顿前后的部分，然后使用音频合并器将它们重新合并在一起。

为什么下载出来是 WAV？

WAV 是您的浏览器无需额外软件即可原生创建的格式，它保持音频正如解码后的样子。如果您之后需要修剪后的文件为 MP3，请使用音频转换器。
