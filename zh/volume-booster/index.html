常见问题

音量增强器免费吗？

是的。它完全免费，无需注册，没有水印，我们没有强加限制。

我的音频文件会上传到服务器吗？

不会。您的文件使用 Web Audio API 100% 在您的浏览器内解码和放大。它从不离开您的设备。

什么是削波，为什么有警告？

数字音频的最大电平为 100%。如果增强将采样推过该限制，它们会被平直地切掉——那就是削波，听起来像刺耳的失真。每当您选择的增强会将最响的峰值推过 100% 时，警告就会出现，这样您可以在它发生之前降低增强或使用归一化。

归一化做什么？

归一化测量整个文件中最响的时刻，并缩放一切，使该峰值正好落在 100%——文件在没有任何削波的情况下可以达到的最响。带有一个响亮时刻的安静录音不会获得多少；均匀安静的录音会获得很多。

300% 是多少分贝？

300% 音量约为 +9.5 dB。200% 约为 +6 dB，50% 约为 -6 dB。拖动时，工具会在滑块旁边显示确切的 dB 值。

工作原理

您的文件在您的浏览器内打开，并使用 Web Audio API 解码为原始声音采样——不上传到任何服务器。工具测量文件中的最高采样（其峰值），在离线渲染中将每个采样乘以您选择的增益，如果结果将超过 100% 数字上限则警告您，并将结果保存为 WAV 文件。

实际示例

您在手机上录制了一次采访，最响的时刻仅达到最大电平的 30%。您加载文件，并不猜测滑块值，而是勾选“改为归一化”。整个采访被放大了约 3.3 倍，使其峰值正好达到 100%——每个词现在都尽可能地响亮且安全，没有失真，您下载 WAV。

增强和归一化都会在提高声音的同时提高噪声，因此请从您拥有的最干净的录音开始。

更多问题

增强会去除背景噪声吗？

不会——增强会将一切一起变响，包括原始录音中的任何嘶嘶声或房间噪声。它不能清洁音频，只能提高其电平。

为什么下载的文件比我的 MP3 大？

导出是 WAV，您的浏览器可以原生创建的未压缩格式。它保持音频正如渲染后的样子，但文件比 MP3 大。任何标准转换器之后都可以将 WAV 变成 MP3。

我的录音在一个地方响亮，在其他地方安静。我该怎么办？

那是一个动态问题，而不是普通的音量问题。归一化只会有一点帮助，因为那个响亮的时刻设定了限制。用音频剪切器剪掉或单独增强安静的部分通常效果更好。
