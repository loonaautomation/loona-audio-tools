屏幕录像机 - 免费在线录制您的屏幕

简而言之： 屏幕录像机捕获您的屏幕、浏览器选项卡或单个窗口——完全免费，不上传任何东西，视频下载为 WebM 文件。

设计上的隐私： 屏幕捕获完全在您的浏览器内进行。录音在您录制时保留在浏览器的内存中，仅当您点击“下载”时才保存。任何东西都不会上传到服务器，关闭选项卡会删除一切。

如何录制您的屏幕

  1. 如果您想旁白，勾选“麦克风音频”；如果选项卡的声音应被录制，勾选“系统/选项卡音频”（桌面版 Chrome 或 Edge）。
  2. 点击“开始录制”，并在浏览器的选择器中选择要共享的内容：浏览器选项卡、窗口或整个屏幕。
  3. 做您想展示的事情——顶部的计时器显示您已经录制了多长时间。此选项卡保留在捕获的背景中，而不是在其中，除非您共享整个屏幕。
  4. 点击“停止录制”（或浏览器自己的“停止共享”栏）。观看预览，然后点击“下载录音”以保存 WebM 文件。

常见问题

屏幕录像机免费吗？

是的。它完全免费，无需注册，没有水印，我们没有强加录制限制。

我的屏幕录像会上传到服务器吗？

不会。录音在您录制时完全在您的浏览器内捕获和存储，完成的文件在您下载时在您的设备上创建。从不上传任何东西。

录音以什么格式下载？

Chrome、Edge 和 Firefox 中的 WebM（较新 Safari 版本中的 MP4）。WebM 在所有现代浏览器中播放，并直接上传到 YouTube 和大多数其他平台。

我可以录制电脑的声音以及我的声音吗？

您的声音：是的——勾选“麦克风音频”并允许麦克风访问。来自电脑本身的声音（系统/选项卡音频）仅在桌面版 Chrome 和 Edge 中工作，并且仅当您共享浏览器选项卡并在选择器中勾选共享音频选项时。其他浏览器无法捕获系统音频——那是浏览器限制，不是任何网站可以改变的。

哪些浏览器支持屏幕录制？

桌面版 Chrome、Edge 和 Firefox 完全支持它。Safari 从 macOS 上的 14.1 版本开始支持它。在手机上，大多数移动浏览器不允许网站录制屏幕——请为此工具使用桌面浏览器。

工作原理

当您按下“开始”时，您浏览器内置的屏幕捕获功能 (getDisplayMedia) 显示它自己的选择器，并将您正好选择的内容的实时视频流交给此页面——不多。此页面使用浏览器的 MediaRecorder 现场录制该流。完成的视频在您浏览器的内存中组装并作为下载提供；没有服务器看到过一帧。

实际示例

您想向学生展示如何在学校门户上提交表格。您勾选“麦克风音频”，点击“开始”，选择带有门户的浏览器选项卡，在大声解释每个步骤的同时慢慢填写表格，然后在 1 分钟 40 秒后停止录音。您预览视频，下载 WebM 文件，并发送它——总成本为零，学生的数据从未接触任何服务器。

因为浏览器本身控制选择器和“停止共享”栏，您始终掌控一切：录音只能包含您选择的内容，并且在您说停的那一刻结束。

更多问题

为什么选择器没有提供任何音频？

系统音频仅在桌面版 Chrome 和 Edge 中提供，且仅适用于浏览器选项卡——窗口和全屏在这些浏览器中始终无声。您的麦克风则通过“麦克风音频”勾选框在每个受支持的浏览器中工作。

我的录音没有声音——出了什么问题？

检查三件事：“麦克风音频”框已勾选且权限已允许；对于选项卡声音，选择器中的“共享选项卡音频”开关已打开；并且选项卡在录制时确实在播放声音。无声的来源会录制为静音。

我可以录制多长时间？

我们没有限制，但录音在您下载它之前保留在浏览器的内存中。非常长的录音（数小时）可能会在较小的设备上耗尽内存——对于长会话，请分部分录制。

如果我按浏览器的“停止共享”而不是“停止”按钮会怎样？

那样也可以。录音完成，您的预览和下载出现，就像您使用了此页面上的“停止”按钮一样。
