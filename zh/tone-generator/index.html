常见问题

音调生成器免费吗？

有任何东西上传到服务器吗？

不会。音调使用 Web Audio API 在您的浏览器内实时合成。WAV 下载也在您的设备上创建。

它可以生成什么频率？

从 20 Hz 到 20,000 Hz——人类听力的标准范围。您是否真的听到极端值取决于您的扬声器或耳机以及您自己的耳朵：小型手机扬声器无法再现 20 Hz，大多数成年人在 14 到 17 kHz 之间的某处停止听到。

波形之间有什么区别？

正弦波是单个纯频率。三角波是带有微弱谐波的较柔和音调，方波是带有强烈奇次谐波的空洞嗡嗡声，锯齿波是最明亮的，包含每个谐波。扬声器测试通常用正弦音调完成。

为什么 440 Hz 重要？

440 Hz 是音符 A4，国际标准音高，管弦乐队以此调音。如果您在演奏 A 的乐器旁边播放它，您可以调整乐器，直到两者匹配。

工作原理

音调使用 Web Audio API 在您的浏览器内以数学方式合成——一个振荡器以您设置的精确频率产生您选择的精确波形。下载将相同的波形逐个采样地渲染到标准 WAV 文件中，因此您保存的文件与您听到的相符。

实际示例

您买了一个额定低至 40 Hz 的小低音炮，想诚实地检查它。您将正弦音调设置为 50 Hz，然后 40 Hz，然后 30 Hz，每个播放几秒钟。50 和 40 Hz 的音调被清楚地感觉到，30 Hz 的音调在此扬声器上是无声的——因此它在您房间中的真实限制约为 40 Hz，正如额定的。

一个安全提示：测试音调——尤其是高频和方波——在相同的音量设置下可能比音乐刺耳得多。始终从低音量开始，慢慢提高。

更多问题

我可以用这个测试我的听力吗？

您可以通过慢慢提高频率直到音调消失来探索您的听力范围取乐——但请保持音量低，并记住这不是医学测试。正确的听力检查需要校准的设备。

为什么下载的 WAV 是立体声？

下载在两个声道上包含相同的音调，因此它在双耳中相同播放，并可在任何播放器或编辑器中作为测试文件工作。

音调在非常低的音量步进下听起来有噼啪声——这正常吗？

方波和锯齿波音调由于其谐波而自然刺耳。对于平滑的参考测试，请使用正弦波形。
