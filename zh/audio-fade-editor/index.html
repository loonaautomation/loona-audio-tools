常见问题

音频淡入淡出编辑器免费吗？

是的。它完全免费，无需注册，没有水印，我们没有强加限制。

我的音频文件会上传到服务器吗？

不会。您的文件使用 Web Audio API 100% 在您的浏览器内解码和淡化。它从不离开您的设备。

淡入淡出可以多长？

每个淡入淡出可以从 0（无淡入淡出）到 10 秒，以半秒为步进。如果两个淡入淡出加起来比文件更长，它们会在中间重叠——工具会警告您，因为那样音频永远不会达到全音量。

淡入淡出是直线还是曲线？

它们是平滑的直线（线性）斜坡：音量在淡入过程中从静音均匀上升到全音量，并在淡出过程中均匀回落到静音。线性淡入淡出是介绍、结尾和语音片段的标准选择。

我可以使用哪些格式？

您的浏览器可以解码的任何格式——在所有现代浏览器中包括 MP3、WAV、M4A 和 OGG。结果以标准 WAV 文件下载，可随处播放。

工作原理

您的文件在您的浏览器内打开，并使用 Web Audio API 解码为原始声音采样——不上传到任何服务器。在离线渲染期间，音量控制在开头您的淡入秒数内将电平从静音平滑地提升到全音量，并在结尾您的淡出秒数内将其降回静音，结果保存为 WAV 文件。

实际示例

您有一段 30 秒的视频背景音乐片段，它突然开始和停止。您将淡入设置为 3 秒，淡出设置为 5 秒。现在音乐在您的开场镜头下温和地升起，并在视频的最后 5 秒中融化消失，而不是切断——您下载已准备好使用的 WAV。

淡入淡出还会去除许多录音在最开始或结尾处的小点击声，因为电平现在以真正的静音开始和结束。

更多问题

什么淡入淡出长度效果最好？

对于歌曲和播客介绍，2-5 秒感觉自然。对于语音备忘录和铃声，0.5-1 秒通常足以去除开头和结尾的点击声。

为什么下载的文件比我的 MP3 大？

导出是 WAV，您的浏览器可以原生创建的未压缩格式。它保持音频正如淡化后的样子，但文件比 MP3 大。任何标准转换器之后都可以将 WAV 变成 MP3。

我可以只淡入开头或只淡出结尾吗？

是的——将您不想要的淡入淡出设置为 0 秒，它就正如原来一样保留。
