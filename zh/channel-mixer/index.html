常见问题

声道混合器免费吗？

是的。它完全免费，无需注册，没有水印，我们没有强加限制。

我的音频文件会上传到服务器吗？

不会。您的文件使用 Web Audio API 100% 在您的浏览器内解码和转换。它从不离开您的设备。

立体声转单声道如何工作？

左右采样的每一对都被平均为单个采样。结果在双耳中相同播放。仅作为声道之间差异存在的声音可能会变得更安静——这是立体声本身的一个属性，在页面上的提示文本中诚实地解释了。

单声道转立体声会让声音更丰富吗？

不会——它将相同的信号复制到两个声道，因此文件成为一个正确的立体声文件，在双耳中居中播放，但不会创建新的立体声信息。这正是大多数播放器和上传表单所需要的。

我的录音只能在一只耳朵播放。哪个选项可以修复它？

如果声音在左耳，使用“仅左声道”；如果声音在右耳，使用“仅右声道”。工作声道被复制到两侧，因此录音在双耳中居中播放。

工作原理

您的文件在您的浏览器内打开，并使用 Web Audio API 解码为单独的左右采样流——不上传到任何服务器。每次转换都是简单、精确的采样数学：单声道逐个采样地平均声道，立体声复制，交换交换它们，单侧模式将所选声道复制到另一个声道上。结果以原始采样率写入标准 WAV 文件。

因为数学是精确的，没有任何东西被重新压缩，也没有任何东西被猜测：您在预览中听到的正是下载文件所包含的。

实际示例

一位教师用立体声麦克风录制采访，但嘉宾坐的那一侧的线缆坏了，没有声音——嘉宾的声音只能在左耳听到。她选择“仅左声道”，下载的 WAV 将嘉宾的声音居中地在双耳播放，可以与全班分享。

更多问题

我可以将立体声歌曲重新分离为人声和乐器吗？

不会——那不是声道操作。一旦声音混合到两个声道中，声道工具只能混合、复制或交换这些声道，而不能解混原始声音。

当我在单声道文件上交换声道时会发生什么？

什么都不变——只有一个声道，所以没有什么可交换的。工具将文件原样传递为单声道 WAV。

为什么下载出来是 WAV？

WAV 是您的浏览器无需额外软件即可原生创建的格式，它保持转换后的声道正如计算的样子。如果您之后需要 MP3，请使用音频转换器。
