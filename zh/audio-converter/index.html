常见问题

音频转换器免费吗？

是的。它完全免费，无需注册，没有水印，我们没有强加限制。

我的音频文件会上传到服务器吗？

不会。您的文件 100% 在您的浏览器内解码和转换。它从不离开您的设备。

我可以从哪些格式转换？

您的浏览器可以解码的任何格式——解码取决于浏览器。Chrome 和 Edge 可解码 MP3、WAV、OGG、M4A、WebM、Opus 和 FLAC；Firefox 可解码其中大部分；Safari 可解码 MP3、WAV 和 M4A，但不能解码 OGG 或 WebM 音频。如果文件无法加载，说明该浏览器无法解码它——请尝试其他浏览器。

我可以转换到哪些格式？

WAV（16 位 PCM，由工具原生编码）和 MP3 以 128、192 或 320 kbps，用 lamejs MP3 编码器在本地编码。您文件的采样率在两种格式中都得到保留。

将 MP3 转换为 WAV 会让它听起来更好吗？

不会。WAV 准确存储解码 MP3 产生的声音——转换无法恢复 MP3 压缩已经去除的质量。WAV 对于编辑仍然有用，因为编辑器在处理它时不用再压缩。

工作原理

您的文件在您的浏览器内打开，并使用 Web Audio API 解码为原始声音采样——不上传到任何服务器。对于 WAV 输出，那些采样以原始采样率直接写入标准 16 位 WAV 文件。对于 MP3 输出，相同的采样由 lamejs 在您的设备上编码，lamejs 是一个著名的编译为在浏览器中运行的 MP3 编码器，以您选择的比特率。

因为采样率得到保留，44,100 Hz 的录音保持 44,100 Hz，48,000 Hz 的录音保持 48,000 Hz——工具从不悄悄地对您的音频重新采样。时长也不变；只有容器和压缩发生变化。

实际示例

您用录音机录制了一段讲解，它保存为您的学校应用不接受的 WebM 文件。您将 WebM 文件拖到此处，选择 192 kbps 的 MP3，然后按“转换”。一分钟后，您拥有一个标准 MP3——相同的长度，相同的 48,000 Hz 采样率，是 WAV 大小的一小部分——准备好随处分享。

更多问题

我应该选择哪个 MP3 比特率？

128 kbps 对于语音、讲座和语音备忘录已经足够。192 kbps 是音乐的安全全能选择。320 kbps 是 MP3 的最高音质——当文件大小不如保留 MP3 格式所能容纳的每一个细节重要时使用它。

为什么 WAV 输出比 MP3 大得多？

WAV 是未压缩的：一分钟的立体声 CD 质量音频作为 WAV 约为 10 MB，但作为 MP3 仅约 1-2.4 MB，取决于比特率。那个大小差异正是 MP3 压缩的用途。

我可以转换很长的录音吗？

是的，但非常长或非常大的文件取决于您设备的内存，因为整个文件一次在浏览器中解码。大多数歌曲、讲座和语音备忘录工作正常。

如果我的文件无法加载会发生什么？

文件是您的浏览器无法解码的格式，或它已损坏。页面上的消息解释了您的浏览器通常解码哪些格式；尝试 Chrome 或 Edge 可以修复大多数情况。
