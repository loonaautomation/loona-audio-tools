听力训练 - 免费在线音程训练器

简而言之： 听力训练音程训练器播放两个音符，并要求您命名它们之间的距离——带有即时反馈、运行中的分数和连胜，以及三个难度级别——完全免费，在您的浏览器中。

靠耳朵识别音程是唱准音调、转录歌曲和通过音乐考试背后的核心技能。此训练器正是训练这一点：一个根音、其上方的一个第二个音符，以及从半音到八度的十三种可能距离——由您选择的难度级别缩小——每次都以半音解释答案。

您听到第一个音符，然后是更高的第二个音符。它们之间的距离是音程。初学者：《生日快乐》的第二个音符是向上的大二度；《一闪一闪亮晶晶》的前两个音符在音高类上相距纯五度——像这样的锚点歌曲是音乐家学习音程的方式。

设计上的隐私： 听力训练声音使用 Web Audio API 在您的浏览器中本地生成。没有麦克风，没有录音，也没有上传任何东西——关闭选项卡，一切都消失了。

如何使用此工具

  1. 选择难度：简单达到纯四度，中等达到小六度，困难达到完整的八度。
  2. 按“新问题”并收听：第一个音符，然后是更高的第二个音符。
  3. 点击您认为听到的音程。无论如何，正确答案都会变成绿色，并解释半音数。
  4. 使用“重播”再次听到这一对，或“一起播放”将两个音符作为一个和弦听到——然后按“新问题”并建立您的连胜。

常见问题

听力训练训练器免费吗？

是的。它完全免费，无需注册，我们没有强加限制。

什么是音程？

两个音符之间的音高距离，以半音为单位测量。纯五度是 7 个半音——从 C 到 G 的距离。训练器涵盖从小二度（1 个半音）到纯八度（12）的全部十三个音程。

问题和答案是如何检查的？

问题生成器和音程表是经过测试的代码：在 500 多个生成的问题中，每个目标音符都正好是根音上方所选数量的半音，在 MIDI 数字和实际频率上都是，并且每个名称都与标准音程表匹配。

音程总是上行的吗？

是的——在此训练器中，第二个音符总是高于第一个。上行音程是标准起点；下行和和声（一起）识别建立在它们之上，“一起播放”按钮让您初步品尝和声形式。

我到底如何进步？

锚点歌曲：为每个音程配一首您熟悉的、以它开头的歌曲——半音是《大白鲨》主题曲，纯五度是《一闪一闪亮晶晶》，八度是《飞越彩虹》。短暂的日常练习胜过偶尔的长时间练习。

工作原理

每个问题都由经过测试的代码生成：在舒适的范围内选择一个根音（A3 到 F4），在您的难度内绘制一个音程大小，目标音符在平均律中正好计算为根音上方那么多半音。两个音符都通过 Web Audio API 以干净的三角波音调和柔和的包络播放——无采样，无下载。

分数是简单的记账：已提问、正确和当前连胜，仅保留在此选项卡中。关闭页面，分数重置——它是练习，而不是账户。

实际示例

一位合唱学生在一首新歌中总是错过跳到五度的那一步。在中等难度上花十分钟——大多数问题落在 5 到 8 个半音之间——她的分数从猜测变为连续答对 8 题，每次出现纯五度时都能立即认出。

更多问题

为什么两个音程对我来说听起来几乎相同？

相邻的音程（例如大三度与纯四度）在大小上接近。降到简单难度，直到小集合可靠为止，使用“一起播放”将这一对感受为一个声音，然后再次扩大难度。

我可以用我自己的乐器训练吗？

是的——听到一个问题后，在回答之前在您的乐器上找到那两个音符。在真实乐器上与训练器匹配是极好的综合练习。

我的分数会保存在任何地方吗？

不会。分数仅存在于此选项卡中，关闭它时消失。您的练习的任何信息都不会被存储或发送到任何地方。
