鼓音序器 - 免费在线节拍制作器

简而言之： 鼓音序器让您在 16 步网格上构建鼓节奏——kick、snare、闭合和开口 hi-hat，全部在您的浏览器中实时合成，无采样——带 rock、house 和 hip-hop 预设和速度控制，完全免费。

您曾经跟随的每一个节拍都是网格上击打的模式。这个音序器为您提供那个网格：十六步（一小节十六分音符），四种由纯合成制成的经典鼓声——用于 kick 的音高下降正弦波、用于 snare 和踩镲的滤波噪声——以及显示 rock、house 和 hip-hop 如何不同地放置其击打的预设。

第 1、5、9 和 13 步是小节的四个主节拍——大多数 kick 和 snare 模式都围绕它们构建。所有四种声音（kick、snare、闭合 hi-hat、开口 hi-hat）都在您的浏览器中实时合成；没有音频采样，也没有下载任何东西。

设计上的隐私： 鼓音序器使用 Web Audio API 在您的浏览器中本地合成每种声音。没有要下载的采样，没有麦克风，也没有上传任何东西——关闭选项卡，一切都消失了。

如何使用此工具

  1. 选择一个预设来听一个完成的模式，或开始在网格上点击步进——每行是一种鼓声，每列是一个十六分音符步进。
  2. 按“播放”。当前步进在小节循环时以金色勾勒。
  3. 在播放时更改步进、速度和音量——变化在循环到达它们时应用。
  4. 使用“清除网格”从静音开始，并从四个主节拍（第 1、5、9、13 步）向外构建您自己的模式。

常见问题

鼓音序器免费吗？

是的。它完全免费，无需注册，我们没有强加限制。

鼓声是采样吗？

不会——每种声音都是实时合成的。Kick 是一个正弦波，其音高在十分之一秒内从 150 Hz 降至约 42 Hz（经典的电子 kick 配方）；snare 是带通滤波噪声加一个短音调；hi-hat 是高通噪声，闭合的短，开口的长。这就是为什么页面即刻加载，无需下载任何东西。

16 步是什么意思？

一小节分为十六分音符。在 120 BPM 时，每步正好是 0.125 秒，因此第 1、5、9 和 13 步落在小节的四个主节拍上。

为什么模式一直循环？

步进音序器按设计就是一台循环机器——一小节重复播放，以便您可以构建和评判一种律动。更改任何内容，您都会在下一轮听到变化。

我可以保存或下载我的节奏吗？

不是从此页面——它是一个用于演奏和学习模式的现场乐器。要录制节奏，播放它并使用本站的屏幕录像机带声音捕获它，或记下网格：这里的每个预设和模式都只是 64 个开关步进。

工作原理

网格存储为四行十六个开关步进——正是页面与其经过测试的模式引擎共享的模式格式，该引擎将模式扩展为定时的事件（在 120 BPM 时，第 8 步正好在 1.0 秒）。播放使用 Web Audio 时钟上的前视调度器：声音被合成并放置在时间稍前方，因此即使屏幕繁忙，律动也保持紧凑。

四种声音是合成配方，而不是录音。那使页面保持零下载、零采样，并且在每台设备上声音相同。

实际示例

一位音乐老师想让她的班级在没有任何设备的情况下听到不同音乐流派的差异。她以相同的速度加载 Rock（kick 在 1 和 9，snare 在 5 和 13），然后是 House（每个节拍都有 kick），然后是节奏更密集的 Hip-Hop——三个网格，三种律动，全班可以确切地看到和听到发生了什么变化。

更多问题

为什么没有低音线或旋律？

此工具仅是鼓机——节奏优先。旋律乐器将是单独的工具；将此页面保持为四种鼓声使它即时且易于学习。

节拍在非常高或非常低的音量下听起来不同——为什么？

小型扬声器无法忠实再现 kick 的基频（约 42-150 Hz），因此 kick 在手机扬声器上听起来比在耳机上薄。这是物理，不是模式的错误。

我可以制作奇数拍号吗？

网格是一小节 16 个十六分步进。使一行最后的步进留空仅在所有行都同意时才创建更短的循环——对于真正的奇数拍子，本站的节拍器直接涵盖每小节的拍数。
