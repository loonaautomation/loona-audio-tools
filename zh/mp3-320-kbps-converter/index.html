常见问题解答

质量会改变吗？

转换为 WAV 是无损的——解码后的采样被准确地写出。转换为 MP3 是有损的：文件缩小，但一些细节被永久丢弃。将 MP3 转换为 WAV 不会恢复丢失的质量；它仅更改容器。

我的音频文件是私密的吗？

是的。解码和编码使用 Web Audio API 和本地 MP3 编码器 100% 在您的浏览器中进行。文件从不上传、存储或被我们听到。

如果我的浏览器无法解码文件怎么办？

解码取决于您的浏览器：Chrome 和 Edge 解码范围最广；Safari 原生处理 M4A/AAC；Firefox 不解码 M4A/AAC。如果文件无法解码，请尝试其他浏览器。
