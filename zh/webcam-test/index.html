常见问题

摄像头测试免费吗？

是的。它完全免费，无需注册，对您测试的频率没有限制。

我的相机图像会上传到任何地方吗？

不会。您的相机仅在本地、在您自己的浏览器内使用。预览、测量和任何快照都保留在您的设备上——快照仅在您点击“下载”时保存。任何东西都不会发送到任何服务器。

为什么预览像镜子一样移动？

预览默认是镜像的，因为那是您习惯于看到自己的方式，它使构图自然。如果您在镜像开启时拍快照，照片按您所见保存；如果您想要照片正如相机所见的场景（衣服上的文本将正确读取），请关闭镜像。

读数说 720p，但我的相机是 1080p——为什么？

读数显示浏览器实际接收的分辨率，可能低于相机的最大值。光线、USB 带宽、浏览器和其他使用相机的应用都会影响它。关闭其他使用相机的应用，改善光线，然后重新启动测试，给它达到全分辨率的最佳机会。

未找到相机——我应该检查什么？

检查相机是否已插入（或在笔记本电脑上未被遮挡/禁用），没有其他应用正在使用它，并且您已在浏览器的地址栏设置中允许此网站的相机权限。在 Windows 上，还要检查“设置 > 隐私 > 相机”是否允许桌面应用。

工作原理

当您按下“开始”时，浏览器请求您的权限并打开您的相机，要求它提供它能提供的最佳质量。此页面然后读取相机流自己的设置——正在交付的确切宽度、高度和帧率——并直接显示给您，没有估计。快照将当前帧复制到您设备上的绘图画布上，并将其变成标准 PNG 图像。

实际示例

您即将用一台声称 1080p 的新 USB 摄像头录制一节课。您开始测试：画面看起来柔和，读数说 1280 x 720，30 fps。您关闭另一个正在使用相机的应用，在您面前加一盏灯，并重新启动测试——现在读数显示 1920 x 1080。您拍一张快照来仔细检查构图，并录制您的课程，确切知道您的学生将看到什么。

数字重要是因为会议应用经常向您显示一个隐藏真相的小预览。测量真实流告诉您，柔和的画面是相机、光线还是另一个应用在偷走质量。

更多问题

画面暗或有颗粒——我如何修复它？

几乎总是：光线。面对窗户或在您面前放一盏灯（切勿放在身后），并给相机一秒钟时间调整。颗粒感是相机在弱光下提高感光度的结果，所以光线越多，相同分辨率下的画面就越干净。

浏览器说相机被阻止——我如何解除阻止？

点击地址栏左侧的锁定或设置图标，找到“相机”，并将其设置为允许此网站。然后再次按“启动相机”。

我可以将手机用作此测试的相机吗？

是的——在您手机的浏览器中打开此页面，它将直接测试手机的相机。要将手机用作电脑的网络摄像头，您需要在两个设备上都有单独的伴侣应用，这超出了网页能做的。
