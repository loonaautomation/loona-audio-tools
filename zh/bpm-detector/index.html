常见问题

BPM 检测器免费吗？

是的。它完全免费，无需注册，我们没有强加限制。

我的音频文件会上传到服务器吗？

不会。您的文件使用 Web Audio API 100% 在您的浏览器内解码和分析。它从不离开您的设备。

检测有多准确？

在节拍清晰、稳定的音乐上——鼓曲目、流行、电子音乐、节拍器般的录音——使用从 60 到 174 BPM 的已知速度的受控测试被准确检测。在复杂的真实音乐上，最强的模式偶尔可能是您感觉到的速度的一半或两倍，这就是为什么页面显示可信度评级并包括拍速检查。

可信度数字是什么意思？

它将获胜节拍模式的强度与所有速度下的平均模式强度进行比较。节拍清晰的曲目得分 5 或更高；页面将 2.5 及以上的结果称为清晰节拍。稳定的音调或语音得分约 1——没有真正的节拍。

它可以检测哪些速度？

在 40 和 208 BPM 之间，以半 BPM 为步进。几乎所有歌曲，从慢速抒情曲到快速电子曲目，都落在这个范围内。

工作原理

您的文件在您的浏览器内打开，并使用 Web Audio API 解码为原始声音采样——不上传到任何服务器。工具构建一个起始包络：一条曲线，显示声音能量如何逐刻急剧上升，在鼓击、音符起始或其他节拍事件发生的任何地方都会出现峰值。然后它以从 40 到 208 BPM 的每个速度（速度图）测量该曲线，并报告其节奏与峰值最强烈匹配的速度。

可信度评级是答案的一部分，而不是装饰：当没有速度突出时——如语音、稳定的音调，或自由时间的音乐——工具会直白地说出来，而不是编造一个数字。

实际示例

一位舞蹈老师想让课堂音乐约为 120 BPM。她将三首候选歌曲逐一放入检测器：第一首读数为 122 BPM，节拍清晰；第二首为 96 BPM；第三首是一段采访录音，诚实地报告没有清晰的节拍。她选择了第一首歌，每拍秒数 0.492，并据此规划她的编舞。

更多问题

为什么它报告的速度是我预期的两倍（或一半）？

一些节奏在两个层级上同时强烈重复——例如一首同时有慢 kick 和快踩镲模式的曲目。检测器报告整体模式最强的层级。页面上的拍速工具让您确认您感觉到的层级。

它可以检测现场表演的速度吗？

先将表演保存或录制为文件——本站的录音机可以做到这一点——然后在此处加载文件。检测器需要一份完成的录音来分析。

为什么我的语音录音会显示 BPM？

它显示它能找到的最强的重复模式，标记为低可信度，并有明确的“未找到清晰节拍”说明。对于语音，将该数字视为无意义——诚实的读数是可信度说明，而不是数字。
