如何编辑字幕文件

  1. 点击上方框并选择您的 .srt 或 .vtt 文件——或将字幕文本粘贴到框中，或按“加载示例字幕”先试用编辑器。
  2. 每个字幕条都出现在表格中。直接在任何“开始”、“结束”或文本框中键入以更改它；您的键入会随进行而被接收。
  3. 要重新同步整个文件，以秒为单位输入移动量（例如 2.5 如果字幕提前显示 2.5 秒， -2.5 如果它们显示得太晚）并按“移动所有字幕条”。要仅移动文件的一部分，填写“从字幕条 #”和“到字幕条 #”，并使用“仅移动范围”。
  4. 按“查找重叠”以突出显示在下一个开始时仍在屏幕上的任何字幕条，然后“修复重叠”以使每个这样的字幕条正好在下一个开始处结束。
  5. 将修复后的文件下载为 .srt，或如果您的播放器或网站需要该格式，则下载为 WebVTT (.vtt)。

常见问题

字幕编辑器免费吗？

是的。它完全免费，无需注册，没有水印，我们没有强加限制。

我的字幕文件会上传到服务器吗？

不会。您的字幕文件 100% 在您的浏览器内读取和编辑。它从不离开您的设备，也不会存储在任何地方。

此工具可以从视频或音频文件自动创建字幕吗？

不会。此工具编辑已经存在的字幕文件（SRT 和 WebVTT）。将语音自动变成字幕需要语音识别 AI，此工具不做这个——它是一个编辑器，而不是转录器。

SRT 和 WebVTT 之间有什么区别？

SRT (SubRip) 是使用最广泛的字幕格式——YouTube 和大多数视频播放器都接受它。WebVTT 是浏览器中 HTML5 视频播放器所用的网络标准。它们包含相同的字幕条；VTT 将小数分隔符写为点而不是逗号，并以 WEBVTT 标题行开始。此工具打开并保存两者，因此转换只是以另一种格式下载。

为什么我的字幕相对于视频稍微提前或延迟？

通常字幕文件是为视频的不同剪辑制作的——一个带有更长介绍、被删场景，或与您的不同的流媒体发布的版本。如果每个字幕都偏差大致相同的量，在移动框中输入该量（正数使字幕更晚，负数使字幕更早），并一键移动所有字幕。如果字幕一开始同步，但随着视频播放而越来越远，那是帧率不匹配（例如 23.976 fps 字幕对 25 fps 视频）——恒定的移动不能完全修复逐渐漂移。

工作原理

您的字幕文件是纯文本：字幕条列表，每个都有开始时间、结束时间以及一行或多行文本。此编辑器用您的浏览器读取文件，将每个字幕条变成表格的一行，并在您移动、排序或修复字幕条时对时间戳进行简单的算术——内部存储为确切的毫秒。下载然后被写回为标准 SRT 或 WebVTT 文本，在您的设备上生成。因为一切都是文本和算术，工具在页面加载后可以离线工作，并处理带有数千个字幕条的文件。

实际示例

您为一部电影下载字幕，但每个字幕都提前 2.5 秒出现 之前 台词被说出——该文件是为没有录音室介绍的版本制作的。您在此处加载 .srt，键入 2.5 在移动框中并按“移动所有字幕条”：一个读作 00:00:07,000 --> 00:00:09,500 的字幕条现在读作 00:00:09,500 --> 00:00:12,000，并且每个其他字幕条都移动相同的 2.5 秒。您下载 .srt，字幕与语音对齐。

同样的想法修复单个坏部分：如果仅在插入场景之后的字幕条是错的，只需将该范围移动场景的长度。

更多问题

我可以在 YouTube 上使用下载的文件吗？

是的。YouTube 直接接受 .srt 上传（字幕 > 添加语言 > 上传文件）。在此处将您编辑的文件下载为 .srt 并上传它——您设置的时间和文本正是 YouTube 将显示的。

“修复重叠”确切地改变了什么？

它查看每对相邻的字幕条。如果一个字幕条的结束时间晚于下一个字幕条的开始时间，第一个字幕条的结束会被拉回到正好下一个字幕条的开始，因此屏幕上一次只有一个字幕。它从不移动开始时间，也从不删除文本。

我可以打开哪些字幕格式？

SRT (.srt) 和 WebVTT (.vtt)。其他格式如 SSA/ASS 或 TTML 不受此编辑器支持——产生它们的大多数工具可以导出 SRT 副本，然后您可以在此处编辑它。
