常见问题

音频剪切器免费吗？

是的。它完全免费，无需注册，没有水印，我们对您剪切多少没有强加限制。

我的音频文件会上传到服务器吗？

不会。您的文件使用 Web Audio API 100% 在您的浏览器内解码和修剪。它从不离开您的设备。

我可以剪切哪些格式？

您的浏览器可以解码的任何格式——在所有现代浏览器中包括 MP3、WAV、M4A 和 OGG。修剪后的结果以标准 WAV 文件下载，可随处播放。

剪切会降低音质吗？

不会。工具复制开始和结束点之间的确切采样——您保留的部分没有重新压缩，它只是保存为 WAV。

我可以剪切很长的录音吗？

是的，但非常长或非常大的文件取决于您设备的内存，因为整个文件在浏览器中解码。大多数歌曲、讲座和语音备忘录工作正常。

工作原理

您的文件在您的浏览器内打开，并使用 Web Audio API 解码为原始声音采样——不上传到任何服务器。您看到的波形是从那些采样绘制的，两个金色手柄之间的部分是您保留的部分。

实际示例

您录制了一段 4 分钟的讲座片段，但只有中间的讲解重要。您加载文件，将开始手柄拖动到 0:35，结束手柄拖动到 2:10（或在框中键入 35 和 130），按“播放所选部分”检查它，然后下载一个干净的 1 分钟 35 秒的 WAV，正是那段讲解。

因为导出是复制两个点之间的原始采样，而不是重新录制它们，所以您保留的部分听起来与原始文件中的一模一样。

更多问题

剪切有多精确？

您可以将开始和结束时间键入到十分之一秒，并拖动波形手柄进行微调。导出使用确切的采样位置，因此剪切落在您设置的位置。

为什么下载出来是 WAV 而不是 MP3？

WAV 是您的浏览器无需额外软件即可原生创建的格式，它保持音频正如解码后的样子。如果您之后需要 MP3，任何标准转换器都可以将 WAV 变成 MP3。

我可以在下载前只听选定的部分吗？

是的——按“播放所选部分”，只有波形的高亮部分播放，因此您可以在导出前检查剪切。

如果我的文件无法加载会发生什么？

文件可能是您的浏览器无法解码的格式，或它可能已损坏。先在任何播放器应用中将其转换为 WAV 或 MP3 通常可以修复问题。
