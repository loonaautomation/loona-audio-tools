常见问题

波形生成器免费吗？

我的音频文件会上传到服务器吗？

不会。您的文件使用 Web Audio API 100% 在您的浏览器内解码和绘制。它从不离开您的设备。

波形是我音频的真实形状吗？

是的。工具测量您实际文件每列中的最小和最大采样，并准确绘制这些值——响亮的部分画得高，安静的部分画得短，静音画得平坦。

透明背景是做什么用的？

勾选透明后，PNG 根本没有背景，因此您可以将波形放置在照片、彩色幻灯片或视频缩略图上，只有波形形状显示。

我可以制作哪些图像大小？

宽度为 1200、1600 或 2400 像素，高度为 300、400 或 600 像素——大到足以用于封面、幻灯片和社交图像，同时在任何设备上保持快速生成。

工作原理

您的文件在您的浏览器内打开，并使用 Web Audio API 解码为原始声音采样——不上传到任何服务器。采样被分为与您选择的图像宽度相同的列数，每列中最低和最高的采样被测量，那些峰值以您选择的样式和颜色绘制在画布上。您下载的 PNG 直接从该画布导出。

立体声文件绘制为一个组合波形：每列显示任一声道的最高峰值，这是大多数封面和缩略图所用的形状。

实际示例

一位教师完成了一节 2 分钟的音频课程，想为班级群制作一张封面图。她加载 MP3，选择 1600 x 400，在白色背景上选择深绿色填充波形，然后下载 PNG。在她的幻灯片中，波形位于课程标题下方——它的两个高大部分正是她为重点提高声音的两个部分。

更多问题

我可以只为文件的一部分获取波形吗？

先使用音频剪切器修剪文件，然后在此处加载修剪后的 WAV——图像将确切显示该部分。

为什么我的波形在某些地方看起来平坦？

平坦部分是录音中真正安静或静音的部分——绘图忠实于音频。如果整个图像看起来小而平坦，则录音整体安静；音量增强器可以先提高其电平。

我可以将图像下载为 JPG 而不是 PNG 吗？

工具导出 PNG 是因为 PNG 支持透明背景选项并保持边缘清晰。如果设计需要，任何图像编辑器或转换器都可以在几秒钟内将 PNG 变成 JPG。
