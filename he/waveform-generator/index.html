מחולל צורת גל - שמע לתמונת צורת גל באינטרנט בחינם

בקיצור: מחולל צורת הגל הופך כל קובץ שמע לתמונת צורת גל נקייה - אתם בוחרים את הגודל, הצבעים, סגנון מלא או פסים, והאם הרקע שקוף - ואז מורידים אותה כ-PNG, חינמי לחלוטין, והקובץ שלכם לעולם אינו עוזב את המכשיר שלכם.

עטיפות פודקאסט, תמונות ממוזערות לסרטונים, שקפי שיעור ופוסטים חברתיים כולם נראים טוב יותר עם הצורה האמיתית של הצליל עליהם. טענו קובץ שמע והכלי הזה מצייר את צורת הגל האמיתית שלו - נמדדת דגימה אחר דגימה מהקובץ שלכם, לא קישוט - מוכנה להישמט לכל עיצוב.

פרטי מתוך תכנון: קובץ השמע שלכם מתפענח ומצויר 100% בדפדפן שלכם עם Web Audio API. הוא לעולם אינו מועלה לשרת, לעולם אינו נשמר ולעולם אינו נשמע על ידינו - סגרו את הלשונית והכול נעלם.

איך להשתמש בכלי הזה

  1. לחצו על התיבה למעלה או גררו לתוכה את קובץ השמע שלכם - MP3, WAV, M4A ו-OGG כולם עובדים. צורת גל ראשונה מופיעה אוטומטית.
  2. בחרו את רוחב וגובה התמונה, את הסגנון המלא או סגנון הפסים, ואת צבעי צורת הגל והרקע - או סמנו את אפשרות הרקע השקוף לשכבות על.
  3. כל שינוי מצייר מחדש את התמונה מיד, אז כווננו עד שהיא מתאימה לעיצוב שלכם.
  4. לחצו על "הורד PNG" והשתמשו בתמונה בכל מקום - עטיפות, שקפים, תמונות ממוזערות ופוסטים.

שאלות נפוצות

האם מחולל צורת הגל חינמי?

כן. הוא חינמי לחלוטין ללא הרשמה, ללא סימן מים וללא מגבלה המוטלת על ידינו.

האם קבצי השמע שלי מועלים לשרת?

לא. הקובץ שלכם מתפענח ומצויר 100% בתוך הדפדפן שלכם עם Web Audio API. הוא לעולם אינו עוזב את המכשיר שלכם.

האם צורת הגל היא הצורה האמיתית של השמע שלי?

כן. הכלי מודד את הדגימה המינימלית והמקסימלית בכל עמודה של הקובץ בפועל שלכם ומצייר בדיוק את הערכים האלה - חלקים חזקים מציירים גבוה, חלקים שקטים מציירים נמוך, שקט מצייר שטוח.

למה מיועד הרקע השקוף?

עם שקיפות מסומנת, לקובץ ה-PNG אין רקע כלל, כך שתוכלו להציב את צורת הגל מעל תמונה, שקף צבעוני או תמונה ממוזערת של סרטון ורק צורת הגל תוצג.

אילו גדלי תמונה אפשר ליצור?

רוחבים של 1200, 1600 או 2400 פיקסלים וגבהים של 300, 400 או 600 פיקסלים - גדולים מספיק לעטיפות, שקפים ותמונות חברתיות תוך שמירה על יצירה מהירה בכל מכשיר.

איך זה עובד

הקובץ שלכם נפתח ממש בתוך הדפדפן שלכם ומתפענח לדגימות צליל גולמיות עם Web Audio API - שום דבר אינו מועלה לשום שרת. הדגימות מחולקות לכמה עמודות כרוחב התמונה שבחרתם, הדגימה הנמוכה והגבוהה ביותר בכל עמודה נמדדת, והפסגות האלה מצוירות על בד בצבעים ובסגנון שבחרתם. קובץ ה-PNG שאתם מורידים מיוצא ישירות מהבד הזה.

קבצי סטריאו מצוירים כצורת גל משולבת אחת: כל עמודה מציגה את הפסגה הגבוהה ביותר משני הערוצים, שהיא הצורה שרוב העטיפות והתמונות הממוזערות משתמשות בה.

דוגמה מעובדת

מורה מסיימת שיעור שמע של 2 דקות ורוצה תמונת עטיפה לקבוצת הכיתה. היא טוענת את קובץ ה-MP3, בוחרת 1600 x 400, צורת גל מלאה בירוק כהה על לבן, ומורידה את ה-PNG. בשקף שלה צורת הגל יושבת מתחת לכותרת השיעור - ושני החלקים הגבוהים שלה הם בדיוק שני החלקים שבהם הרימה את קולה לנקודות המפתח.

שאלות נוספות

האם אפשר לקבל צורת גל רק לחלק מקובץ?

גזרו את הקובץ תחילה עם חותך השמע, ואז טענו את קובץ ה-WAV הגזום כאן - התמונה תציג בדיוק את החלק הזה.

למה צורת הגל שלי נראית שטוחה במקומות?

מקטעים שטוחים הם חלקים שקטים או דוממים באמת של ההקלטה - הציור נאמן לשמע. אם כל התמונה נראית קטנה ושטוחה, ההקלטה שקטה בסך הכול; מגביר עוצמת הקול יכול להעלות את רמתה תחילה.

האם אפשר להוריד את התמונה כ-JPG במקום PNG?

הכלי מייצא PNG כי PNG תומך באפשרות הרקע השקוף ושומר את הקצוות חדים. כל עורך תמונות או ממיר יכול להפוך את ה-PNG ל-JPG תוך שניות אם עיצוב דורש זאת.
