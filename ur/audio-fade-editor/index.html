فیڈز کتنے لمبے ہو سکتے ہیں؟

ہر فیڈ 0 (کوئی فیڈ نہیں) سے 10 سیکنڈ تک ہو سکتا ہے، نصف سیکنڈ کے مراحل میں۔ اگر دونوں فیڈز مل کر فائل سے لمبے ہوں تو وہ درمیان میں اوورلیپ کرتے ہیں - ٹول آپ کو خبردار کرتا ہے، کیونکہ اس صورت میں آڈیو کبھی پوری آواز تک نہیں پہنچتی۔

کیا فیڈز سیدھی لکیریں ہیں یا خم دار؟

یہ ہموار سیدھے (لکیری) ریمپ ہیں: والیوم فیڈ اِن کے دوران خاموشی سے پورے تک یکساں بڑھتا ہے، اور فیڈ آؤٹ کے دوران یکساں واپس خاموشی تک گرتا ہے۔ لکیری فیڈز تعارف، اختتام اور آواز کلپس کے لیے معیاری انتخاب ہیں۔

میں کن فارمیٹس کو استعمال کر سکتا ہوں؟

کوئی بھی فارمیٹ جو آپ کا براؤزر ڈی کوڈ کر سکے - تمام جدید براؤزرز میں MP3، WAV، M4A اور OGG۔ نتیجہ معیاری WAV فائل کے طور پر ڈاؤن لوڈ ہوتا ہے جو ہر جگہ چلتی ہے۔

یہ کیسے کام کرتا ہے

آپ کی فائل بالکل آپ کے براؤزر کے اندر کھلتی ہے اور Web Audio API کے ساتھ خام آواز نمونوں میں ڈی کوڈ ہوتی ہے - کسی سرور پر کچھ اپ لوڈ نہیں ہوتا۔ آف لائن تیاری کے دوران، والیوم کنٹرول شروع میں آپ کے فیڈ اِن سیکنڈوں میں سطح کو خاموشی سے پورے تک نرمی سے بڑھاتا ہے، اور آخر میں آپ کے فیڈ آؤٹ سیکنڈوں میں اسے واپس خاموشی تک کم کرتا ہے، اور نتیجہ WAV فائل کے طور پر محفوظ ہوتا ہے۔
