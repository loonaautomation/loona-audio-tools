آڈیو جوائنر - آڈیو فائلیں ایک ٹریک میں جوڑیں

مختصراً: آڈیو جوائنر دو یا زیادہ آڈیو فائلوں کو ایک ٹریک میں جوڑتا ہے، بالکل اسی ترتیب میں جو آپ مقرر کریں - مکمل طور پر مفت، اور آپ کی فائلیں کبھی آپ کی ڈیوائس نہیں چھوڑتیں۔

تین حصوں میں انٹرویو، فائلوں میں بٹی ہوئی گانا، یا الگ الگ ریکارڈ کیے گئے اسباق - یہ ٹول آڈیو فائلوں کو ایک صاف ٹریک میں جوڑ دیتا ہے۔ اپنی فائلیں شامل کریں، ترتیب مقرر کریں، اور جڑی ہوئی آڈیو کو WAV فائل کے طور پر ڈاؤن لوڈ کریں۔

کیا آڈیو جوائنر مفت ہے؟

کیا میری آڈیو فائلیں سرور پر اپ لوڈ ہوتی ہیں؟

نہیں۔ ہر فائل Web Audio API کے ساتھ 100% آپ کے براؤزر کے اندر ڈی کوڈ اور جوڑی جاتی ہے۔ آپ کی آڈیو کبھی آپ کی ڈیوائس نہیں چھوڑتی۔

میں کن فارمیٹس کو آپس میں جوڑ سکتا ہوں؟

فارمیٹس کا کوئی بھی مجموعہ جو آپ کا براؤزر ڈی کوڈ کر سکے - MP3، WAV، M4A اور OGG۔ مختلف فارمیٹس والی فائلیں آپس میں اچھی طرح جڑ جاتی ہیں، اور نتیجہ ایک معیاری WAV فائل کے طور پر ڈاؤن لوڈ ہوتا ہے۔

کیا میں فائلوں کی ترتیب بدل سکتا ہوں؟

ہاں۔ جوڑنے سے پہلے درست ترتیب مقرر کرنے کے لیے ہر فائل کے ساتھ اوپر اور نیچے بٹن استعمال کریں۔

کیا جڑی ہوئی آڈیو کوالٹی کھو دے گی؟

نہیں۔ ٹول ہر فائل کے اصل نمونے ایک کے بعد ایک رکھتا ہے - کچھ دوبارہ کمپریس نہیں ہوتا - اور نتیجہ WAV کے طور پر محفوظ کرتا ہے۔

یہ کیسے کام کرتا ہے

جو فائل آپ شامل کرتے ہیں وہ آپ کے براؤزر کے اندر Web Audio API کے ساتھ خام آواز کے نمونوں میں ڈی کوڈ ہوتی ہے - کسی سرور پر کچھ اپ لوڈ نہیں ہوتا۔ جب آپ Join دبائیں تو ٹول پہلی فائل کے نمونے، پھر دوسری کے، پھر تیسری کے، بالکل اسی ترتیب میں جو آپ کی فہرست میں دکھائی گئی ہے، سیدھ میں لگاتا ہے اور انہیں ایک نئی WAV فائل میں لکھ دیتا ہے۔
