کلپنگ کیا ہے، اور انتباہ کیوں؟

ڈیجیٹل آڈیو کی زیادہ سے زیادہ سطح 100% ہوتی ہے۔ اگر بڑھانا نمونوں کو اس حد سے آگے دھکیل دے تو وہ چپٹے کٹ جاتے ہیں - یہ کلپنگ ہے، اور یہ سخت بگاڑ جیسی سنائی دیتی ہے۔ انتباہ اس وقت ظاہر ہوتا ہے جب آپ کی منتخب بڑھوتری بلند ترین چوٹی کو 100% سے آگے دھکیل دے، تاکہ آپ اس سے پہلے بڑھوتری کم کر سکیں یا Normalize استعمال کر سکیں۔

Normalize کیا کرتا ہے؟

Normalize پوری فائل میں بلند ترین لمحہ ناپتا ہے اور ہر چیز کو اس طرح پیمانہ کرتا ہے کہ وہ چوٹی بالکل 100% پر آئے - فائل کسی کلپنگ کے بغیر جتنی بلند ہو سکتی ہے۔ ایک بلند لمحے والی خاموش ریکارڈنگز زیادہ حاصل نہیں کریں گی؛ یکساں خاموش ریکارڈنگز بہت حاصل کرتی ہیں۔

300% کتنے ڈیسیبل ہے؟

300% والیوم تقریباً +9.5 dB ہے۔ 200% تقریباً +6 dB ہے اور 50% تقریباً -6 dB ہے۔ جب آپ سلائیڈر گھسیٹتے ہیں تو ٹول اس کے ساتھ درست dB قدر دکھاتا ہے۔

یہ کیسے کام کرتا ہے

آپ کی فائل بالکل آپ کے براؤزر کے اندر کھلتی ہے اور Web Audio API کے ساتھ خام آواز نمونوں میں ڈی کوڈ ہوتی ہے - کسی سرور پر کچھ اپ لوڈ نہیں ہوتا۔ ٹول فائل میں سب سے زیادہ نمونہ (اس کی چوٹی) ناپتا ہے، آف لائن تیاری میں ہر نمونے کو آپ کے منتخب فائدے سے ضرب دیتا ہے، اگر نتیجہ 100% ڈیجیٹل حد سے گزرے تو آپ کو خبردار کرتا ہے، اور نتیجہ WAV فائل کے طور پر محفوظ کرتا ہے۔
