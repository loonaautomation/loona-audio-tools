کیا آڈیو ریورسر مفت ہے؟

ہاں۔ یہ مکمل طور پر مفت ہے بغیر سائن اپ، بغیر واٹر مارک اور ہماری طرف سے عائد کوئی حد نہیں۔

کیا میری آڈیو فائلیں سرور پر اپ لوڈ ہوتی ہیں؟

نہیں۔ آپ کی فائل Web Audio API کے ساتھ 100% آپ کے براؤزر کے اندر ڈی کوڈ اور الٹی جاتی ہے۔ یہ کبھی آپ کی ڈیوائس نہیں چھوڑتی۔

کیا الٹنے سے لمبائی یا کوالٹی بدل جاتی ہے؟

نہیں۔ الٹی فائل کی مدت، سیمپل ریٹ اور چینلز بالکل اصل جیسے ہیں - نمونے صرف مخالف ترتیب میں چلائے جاتے ہیں، اس لیے کچھ ضائع یا دوبارہ کمپریس نہیں ہوتا۔

میں کن فارمیٹس کو الٹ سکتا ہوں؟

کوئی بھی فارمیٹ جو آپ کا براؤزر ڈی کوڈ کر سکے - تمام جدید براؤزرز میں MP3، WAV، M4A اور OGG۔ نتیجہ معیاری WAV فائل کے طور پر ڈاؤن لوڈ ہوتا ہے جو ہر جگہ چلتی ہے۔

الٹی آوازیں اتنی عجیب کیوں سنائی دیتی ہیں؟

کیونکہ آوازیں قدرتی طور پر مدھم ہو جاتی ہیں (جیسے پیانو کا نوٹ) مگر الٹی آوازیں پھول کر اندر آتی ہیں اور اچانک رک جاتی ہیں۔ آپ کا دماغ اس غیر فطری لفافے کو فوراً نوٹ کرتا ہے - یہی وجہ ہے کہ الٹے سمبلز موسیقی اور ویڈیو میں کلاسک منتقلی اثر ہیں۔

یہ کیسے کام کرتا ہے

آپ کی فائل بالکل آپ کے براؤزر کے اندر کھلتی ہے اور Web Audio API کے ساتھ خام آواز نمونوں میں ڈی کوڈ ہوتی ہے - کسی سرور پر کچھ اپ لوڈ نہیں ہوتا۔ ٹول پھر نمونوں کو نئی ریکارڈنگ میں بالکل مخالف ترتیب میں لکھتا ہے، پہلا نمونہ آخری اور آخری نمونہ پہلا، ہر چینل کے لیے، اور نتیجہ WAV فائل کے طور پر محفوظ کرتا ہے۔

عملی مثال

آپ خود کو "Loona Audio Tools" کہتے ہوئے ریکارڈ کرتے ہیں اور کلپ یہاں لوڈ کرتے ہیں۔ "Play Reversed" دبانا فقرہ الٹا چلاتا ہے - یہ پراسرار غیر ملکی زبان جیسا سنائی دیتا ہے۔ آپ WAV ڈاؤن لوڈ کرتے ہیں، اور اگر آپ کبھی اس فائل کو اسی ٹول سے دوبارہ الٹیں تو آپ کو اپنی اصل ریکارڈنگ واپس ملتی ہے، نمونہ بہ نمونہ۔

دو بار الٹنا ہمیشہ اصل کو بالکل بحال کر دیتا ہے، کیونکہ کوئی نمونہ نہیں بدلتا - صرف ان کی ترتیب۔
