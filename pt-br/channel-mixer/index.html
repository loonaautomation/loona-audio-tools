Perguntas Frequentes

O Mixer de Canais é grátis?

Sim. É totalmente grátis, sem cadastro, sem marca d'água e sem limite imposto por nós.

Meus arquivos de áudio são enviados para um servidor?

Não. Seu arquivo é decodificado e convertido 100% dentro do seu navegador com a Web Audio API. Ele nunca sai do seu dispositivo.

Como funciona Estéreo para Mono?

Cada par de amostras esquerda e direita é calculado como média em uma única amostra. O resultado toca identicamente nos dois ouvidos. Sons que existem apenas como diferença entre os canais podem ficar mais baixos - isso é uma propriedade do próprio estéreo, explicada com honestidade no texto de dica da página.

Mono para Estéreo deixa o som mais rico?

Não - ela copia o mesmo sinal para os dois canais, então o arquivo vira um arquivo estéreo de verdade que toca centralizado nos dois ouvidos, mas nenhuma informação estéreo nova é criada. Isso é exatamente o que a maioria dos players e formulários de envio precisa.

Minha gravação só toca em um ouvido. Qual opção resolve isso?

Somente Canal Esquerdo se o som estiver no ouvido esquerdo, ou Somente Canal Direito se estiver no ouvido direito. O canal que funciona é copiado para os dois lados, então a gravação toca centralizada nos dois ouvidos.

Como funciona

Seu arquivo é aberto bem dentro do seu navegador e decodificado em fluxos de amostras esquerdo e direito separados com a Web Audio API - nada é enviado para nenhum servidor. Cada conversão é matemática de amostras simples e exata: mono calcula a média dos canais amostra por amostra, estéreo duplica, trocar inverte, e os modos de um lado copiam o canal escolhido sobre o outro. O resultado é escrito como arquivo WAV padrão na taxa de amostragem original.

Porque a matemática é exata, nada é recomprimido e nada é adivinhado: o que você ouve na prévia é exatamente o que o arquivo baixado contém.

Exemplo prático

Uma professora grava uma entrevista com um microfone estéreo, mas o convidado sentou do lado que o cabo com defeito silenciou - o convidado só é audível no ouvido esquerdo. Ela escolhe Somente Canal Esquerdo, e o WAV baixado reproduz o convidado centralizado nos dois ouvidos, pronto para compartilhar com a turma.

Mais perguntas

Posso separar uma música estéreo de volta em vocais e instrumentos?

Não - isso não é uma operação de canais. Depois que os sons são misturados em dois canais, ferramentas de canais só conseguem misturar, copiar ou trocar esses canais, não desmisturar os sons originais.

O que acontece quando troco os canais de um arquivo mono?

Nada muda - há apenas um canal, então não há nada para trocar. A ferramenta passa o arquivo inalterado como WAV mono.

Por que o download sai como WAV?

WAV é o formato que seu navegador consegue criar nativamente sem software extra, e mantém os canais convertidos exatamente como calculados. Use o Conversor de Áudio se precisar de MP3 depois.
