ตัวตรวจจับ BPM - ค้นหาจังหวะความเร็วของเพลงออนไลน์ฟรี

กล่าวโดยสรุป: ตัวตรวจจับ BPM ค้นหาจังหวะความเร็วของเพลงหรือไฟล์บันทึกเป็นจังหวะต่อนาที แสดงว่ามันมั่นใจในการตรวจจับแค่ไหน และบอกคุณอย่างตรงไปตรงมาเมื่อไฟล์ไม่มีจังหวะที่ชัดเจนเลย - ฟรีทั้งหมด และไฟล์ของคุณไม่เคยออกจากอุปกรณ์ของคุณ

ดีเจที่กำลังเรียงสองแทร็กให้ตรงกัน ครูที่กำลังเลือกเพลงด้วยจังหวะที่เหมาะกับกิจกรรม นักเต้นและนักตัดต่อที่นับจังหวะ - พวกเขาทุกคนเริ่มต้นด้วยตัวเลขเดียว: BPM โหลดไฟล์แล้วเครื่องมือนี้จะวัดจังหวะเกิดซ้ำที่แรงที่สุด แสดงระดับความมั่นใจด้วยภาษาที่เข้าใจง่าย และมอบปุ่มเคาะจังหวะให้คุณตรวจสอบคำตอบด้วยหูของคุณเอง

หรือเคาะจังหวะความเร็วด้วยตัวเอง

เล่นเพลงที่ใดก็ได้และแตะปุ่มนี้ในทุกจังหวะ - หลังจากเคาะไม่กี่ครั้ง จังหวะความเร็วที่คุณเคาะจะปรากฏขึ้น มันจะรีเซ็ตหลังจากหยุดไป 2 วินาที

เป็นส่วนตัวโดยการออกแบบ: ไฟล์เสียงของคุณถูกถอดรหัสและวิเคราะห์ 100% ในเบราว์เซอร์ของคุณด้วย Web Audio API มันไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และเราไม่เคยได้ยินมัน - ปิดแท็บแล้วทุกอย่างก็หายไป

วิธีใช้เครื่องมือนี้

  1. คลิกช่องด้านบนหรือลากไฟล์เสียงของคุณเข้าไป - MP3, WAV, M4A และ OGG ใช้ได้ทั้งหมด การวิเคราะห์จะเริ่มโดยอัตโนมัติ ไฟล์ที่มีความยาว 10 วินาทีขึ้นไปให้ผลลัพธ์ที่เชื่อถือได้มากที่สุด
  2. อ่านจังหวะความเร็วที่ตรวจพบ หมายเหตุเรื่องความมั่นใจ จำนวนวินาทีต่อจังหวะ และจำนวนจังหวะโดยประมาณในไฟล์
  3. หากโน้ตบอกว่าไม่พบจังหวะที่ชัดเจน ให้เชื่อมัน - เสียงพูดและไฟล์บันทึกเสียงบรรยากาศมักไม่มีจังหวะความเร็วที่คงที่ และตัวเลขที่แสดงเป็นเพียงรูปแบบที่แรงที่สุดเท่านั้น
  4. การตรวจสอบเสริม: เล่นแทร็กและแตะปุ่ม "เคาะตามจังหวะ" ในทุกจังหวะ เพื่อเปรียบเทียบจังหวะความเร็วของคุณเองกับตัวตรวจจับ

ตัวตรวจจับ BPM ฟรีหรือไม่

ใช่ มันฟรีทั้งหมดโดยไม่ต้องสมัครสมาชิกและไม่มีขีดจำกัดที่เรากำหนด

ไฟล์เสียงของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่

ไม่ ไฟล์ของคุณถูกถอดรหัสและวิเคราะห์ 100% ภายในเบราว์เซอร์ของคุณด้วย Web Audio API มันไม่เคยออกจากอุปกรณ์ของคุณ

การตรวจจับแม่นยำแค่ไหน

บนเพลงที่มีจังหวะชัดเจนและคงที่ - แทร็กกลอง ป๊อป เพลงอิเล็กทรอนิกส์ ไฟล์บันทึกคล้ายเมโทรนอม - การทดสอบแบบควบคุมด้วยจังหวะความเร็วที่รู้ค่าตั้งแต่ 60 ถึง 174 BPM ตรวจจับได้อย่างแม่นยำ บนเพลงจริงที่ซับซ้อน รูปแบบที่แรงที่สุดบางครั้งอาจเป็นครึ่งหนึ่งหรือสองเท่าของจังหวะความเร็วที่คุณรู้สึก ซึ่งเป็นเหตุผลว่าทำไมหน้านี้จึงแสดงการให้คะแนนความมั่นใจและมีตัวตรวจสอบด้วยการเคาะจังหวะ

ตัวเลขความมั่นใจหมายความว่าอย่างไร

มันเปรียบเทียบความแรงของรูปแบบจังหวะที่ชนะกับความแรงเฉลี่ยของรูปแบบในทุกจังหวะความเร็ว แทร็กที่มีจังหวะชัดเจนจะได้คะแนน 5 ขึ้นไป หน้าเว็บเรียกว่าผลลัพธ์เป็นจังหวะที่ชัดเจนตั้งแต่ 2.5 ขึ้นไป ส่วนโทนเสียงคงที่หรือเสียงพูดจะได้คะแนนประมาณ 1 - ไม่มีจังหวะจริง

มันตรวจจับจังหวะความเร็วใดได้บ้าง

ระหว่าง 40 ถึง 208 BPM ในขั้นละครึ่ง BPM เพลงเกือบทั้งหมด ตั้งแต่เพลงบัลลาดช้า ๆ ไปจนถึงแทร็กอิเล็กทรอนิกส์เร็ว ๆ ล้วนอยู่ในช่วงนี้

วิธีการทำงาน

ไฟล์ของคุณถูกเปิดภายในเบราว์เซอร์ของคุณโดยตรงและถอดรหัสเป็นแซมเปิลเสียงดิบด้วย Web Audio API - ไม่มีอะไรถูกอัปโหลดไปยังเซิร์ฟเวอร์ใด ๆ เครื่องมือสร้างเส้นห่อหุ้มการเริ่มต้น: เส้นโค้งที่แสดงว่าพลังงานเสียงเพิ่มขึ้นอย่างรวดเร็วแค่ไหนในแต่ละขณะ ซึ่งจะพุ่งสูงขึ้นทุกที่ที่มีการตีกลอง การโจมตีของโน้ต หรือเหตุการณ์จังหวะอื่น ๆ เกิดขึ้น จากนั้นมันจะวัดเส้นโค้งนั้นในทุกจังหวะความเร็วตั้งแต่ 40 ถึง 208 BPM (เทมโปแกรม) และรายงานจังหวะความเร็วที่จังหวะของมันตรงกับการพุ่งสูงเหล่านั้นมากที่สุด

การให้คะแนนความมั่นใจเป็นส่วนหนึ่งของคำตอบ ไม่ใช่ของตกแต่ง: เมื่อไม่มีจังหวะความเร็วใดโดดเด่น - เช่นเดียวกับเสียงพูด โทนเสียงคงที่ หรือเพลงที่จับเวลาได้อย่างอิสระ - เครื่องมือจะบอกอย่างตรงไปตรงมาแทนที่จะสร้างตัวเลขขึ้นมา

ตัวอย่างที่ทำจริง

ครูสอนเต้นต้องการเพลงสำหรับชั้นเรียนที่ประมาณ 120 BPM เธอลากเพลงตัวเลือกสามเพลงใส่ตัวตรวจจับทีละเพลง: เพลงแรกอ่านได้ 122 BPM พร้อมจังหวะที่ชัดเจน เพลงที่สองได้ 96 BPM และเพลงที่สามเป็นไฟล์บันทึกการสัมภาษณ์ที่รายงานอย่างตรงไปตรงมาว่าไม่มีจังหวะที่ชัดเจน เธอเลือกเพลงแรก ซึ่งใช้เวลา 0.492 วินาทีต่อจังหวะ และวางแผนท่าเต้นของเธอบนเพลงนั้น

คำถามเพิ่มเติม

ทำไมมันรายงานเป็นสองเท่า (หรือครึ่งหนึ่ง) ของจังหวะความเร็วที่ฉันคาดไว้

จังหวะบางอย่างเกิดซ้ำอย่างแรงในสองระดับพร้อมกัน - ตัวอย่างเช่น แทร็กที่มีทั้งเสียงคิกช้าและรูปแบบแฮตเร็ว ตัวตรวจจับรายงานระดับที่รูปแบบของมันแรงที่สุดโดยรวม เครื่องมือเคาะจังหวะบนหน้าเว็บช่วยให้คุณยืนยันระดับที่คุณรู้สึกได้

มันตรวจจับจังหวะความเร็วของการแสดงสดได้หรือไม่

บันทึกหรืออัดการแสดงเป็นไฟล์ก่อน - เครื่องบันทึกเสียงบนเว็บไซต์นี้ทำแบบนั้นได้ - จากนั้นโหลดไฟล์ที่นี่ ตัวตรวจจับต้องการไฟล์บันทึกที่เสร็จสมบูรณ์เพื่อวิเคราะห์

ทำไมไฟล์บันทึกเสียงพูดของฉันจึงแสดง BPM ด้วย

มันแสดงรูปแบบเกิดซ้ำที่แรงที่สุดที่มันหาได้ ติดป้ายด้วยความมั่นใจต่ำและหมายเหตุที่ชัดเจนว่า "ไม่พบจังหวะที่ชัดเจน" ให้ถือว่าตัวเลขนั้นไม่มีความหมายสำหรับเสียงพูด - สิ่งที่ควรอ่านอย่างตรงไปตรงมาคือหมายเหตุเรื่องความมั่นใจ ไม่ใช่ตัวเลข

ตัวตัดไฟล์เสียง

⏩

ตัวเปลี่ยนความเร็วเสียง

เร่งหรือชะลอเสียงใดก็ได้ ตั้งแต่ 0.25x ถึง 3x - สมบูรณ์แบบสำหรับบทบรรยาย พอดแคสต์ และการเรียนรู้เพลง

🎼

ตัวสร้างโทนเสียง

สร้างโทนเสียงทดสอบบริสุทธิ์ตั้งแต่ 20 Hz ถึง 20,000 Hz ในสี่รูปคลื่นเสียง - ทดสอบลำโพงและหูฟัง ตั้งเสียงเครื่องดนตรี หรือดาวน์โหลดโทนเสียงเป็น WAV

ตัวแปลงไฟล์เสียง

แปลงเสียงระหว่างรูปแบบต่าง ๆ - เปลี่ยน MP3, WAV, OGG, M4A หรือ WebM ให้เป็น WAV หรือ MP3 ที่ 128, 192 หรือ 320 kbps

ฝังเครื่องมือนี้บนเว็บไซต์ของคุณ — ฟรี

เพิ่มเครื่องมือนี้ลงในเว็บไซต์หรือบล็อกของคุณเอง — ใช้ได้ฟรีทั้งหมด ไม่ต้องสมัครสมาชิก และแสดงเวอร์ชันล่าสุดเสมอ คัดลอกโค้ดด้านล่างแล้ววางลงในหน้าของคุณตรงตำแหน่งที่ต้องการให้เครื่องมือปรากฏ การคงบรรทัดเครดิตเล็ก ๆ “Powered by Loona Automation” ไว้ใต้ตัวฝังจะช่วยให้เครื่องมือนี้ยังคงใช้งานได้ฟรีต่อไป — แต่คุณจะปรับแต่งสไตล์หรือลบมันออกก็ได้ตามใจ เครื่องมือทำงานได้ทั้งสองแบบ
