ตัวแปลงไฟล์เสียง - แปลงไฟล์เสียงออนไลน์ฟรี

กล่าวโดยสรุป: ตัวแปลงไฟล์เสียงเปลี่ยนไฟล์เสียงใด ๆ ที่เบราว์เซอร์ของคุณถอดรหัสได้ให้เป็น WAV หรือ MP3 - เลือก MP3 ที่ 128, 192 หรือ 320 kbps สำหรับไฟล์เล็กที่เล่นได้ทุกที่ หรือ WAV สำหรับคุณภาพแบบไม่บีบอัดเต็มที่ - ฟรีทั้งหมด โดยคงอัตราการสุ่มตัวอย่างไว้ และไฟล์ของคุณไม่เคยออกจากอุปกรณ์ของคุณ

บันทึกเสียงที่อยู่ในรูปแบบที่ผิด ไฟล์บันทึก WebM จากเบราว์เซอร์ที่โปรแกรมอื่นเปิดไม่ได้เลย ไฟล์ OGG ที่โทรศัพท์ของคุณไม่ยอมเล่น - เครื่องมือนี้แปลงเสียงให้กลายเป็นสองรูปแบบที่ใช้ได้ทุกที่ โหลดไฟล์หรือบันทึกใหม่ตรงจุดนั้นเลย เปรียบเทียบรูปแบบไฟล์เข้า ระยะเวลา และขนาด กับไฟล์ผลลัพธ์ก่อนที่คุณจะดาวน์โหลด และเก็บทุกอย่างไว้เป็นส่วนตัวบนอุปกรณ์ของคุณเอง

บันทึกเสียง WhatsApp เป็น MP3 ฟรี

กล่าวโดยสรุป: บันทึกเสียง WhatsApp คือเสียง Opus ในตัวบรรจุ OGG — มีประสิทธิภาพ และเล่นไม่ได้ในโปรแกรมแก้ไข รถ และระบบจัดเก็บส่วนใหญ่ การแปลงเป็น MP3 ที่ 128 kbps (เพียงพอมาก

เพิ่งบันทึกอะไรบางอย่างใช่ไหม เครื่องบันทึกเสียง สร้างไฟล์บันทึก WebM หรือ M4A - วางไฟล์หนึ่งที่นี่เพื่อเปลี่ยนมันเป็น MP3 หรือ WAV ต้องการเฉพาะบางส่วนของไฟล์ใช่ไหม ตัดมันก่อนด้วย ตัวตัดไฟล์เสียง, แล้วแปลงไฟล์ WAV ที่ตัดแล้วได้ที่นี่

หมายเหตุตรงไปตรงมาเกี่ยวกับการส่งออก MP3: ไฟล์ MP3 ถูกสร้างโดยตัวเข้ารหัส lamejs ที่มาพร้อมกับเว็บไซต์นี้ (156 KB โหลดเฉพาะในหน้านี้) และเป็น MP3 มาตรฐานที่บิตเรตที่คุณเลือก - แต่ MP3 เป็นรูปแบบที่สูญเสียข้อมูล และตัวแปลงนี้ได้รับการจัดอันดับเป็นบางส่วน (PARTIAL) สำหรับ MP3 ในการวิจัยของเราเอง: คุณภาพถูกจำกัดโดยรูปแบบ MP3 เอง และการถอดรหัสรูปแบบไฟล์เข้าที่หายากขึ้นอยู่กับเบราว์เซอร์ของคุณ การส่งออก WAV คือตัวเลือกที่ไม่สูญเสียข้อมูลและพร้อมใช้งานเสมอ

เป็นส่วนตัวโดยการออกแบบ: ไฟล์เสียงของคุณถูกถอดรหัสและเข้ารหัสใหม่ 100% ในเบราว์เซอร์ของคุณด้วย Web Audio API และตัวเข้ารหัส MP3 ที่ทำงานภายในอุปกรณ์ของคุณ มันไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และเราไม่เคยได้ยินมัน - ปิดแท็บแล้วทุกอย่างก็หายไป

เกี่ยวกับเครื่องมือนี้

บันทึกเสียง WhatsApp คือเสียง Opus ในตัวบรรจุ OGG — มีประสิทธิภาพ และเล่นไม่ได้ในโปรแกรมแก้ไข รถ และระบบจัดเก็บส่วนใหญ่ การแปลงเป็น MP3 ที่ 128 kbps (เพียงพอมากสำหรับเสียงพูด) ทำให้บันทึกนั้นเล่นและแชร์ได้ทุกที่

โน้ตนั้นเองไม่เคยถูกอัปโหลด: ไฟล์ถูกถอดรหัสและเข้ารหัสใหม่ในเบราว์เซอร์ของคุณ บันทึกบันทึกเสียงจาก WhatsApp ลงอุปกรณ์ของคุณก่อน จากนั้นวางมันที่นี่

ตัวอย่างที่ทำจริง

นักข่าวคนหนึ่งเก็บบันทึกเสียงความยาว 2 นาทีของแหล่งข่าวจาก WhatsApp แปลงเป็น MP3 และเก็บเข้าคลังพร้อมกับตัวข่าว — เปิดเล่นได้ในระบบของห้องข่าว

คุณภาพจะเปลี่ยนหรือไม่

การแปลงเป็น WAV ไม่สูญเสียข้อมูล — แซมเปิลที่ถอดรหัสแล้วจะถูกเขียนออกมาอย่างแม่นยำ การแปลงเป็น MP3 สูญเสียข้อมูล: ไฟล์จะเล็กลง แต่รายละเอียดบางส่วนจะถูกทิ้งอย่างถาวร การแปลง MP3 เป็น WAV ไม่ได้ฟื้นฟูคุณภาพที่หายไป มันแค่เปลี่ยนรูปแบบบรรจุเท่านั้น

ไฟล์เสียงของฉันเป็นส่วนตัวหรือไม่

ใช่ การถอดรหัสและการเข้ารหัสเกิดขึ้น 100% ในเบราว์เซอร์ของคุณด้วย Web Audio API และตัวเข้ารหัส MP3 ภายในอุปกรณ์ ไฟล์ไม่เคยถูกอัปโหลด จัดเก็บ หรือฟังโดยเรา

จะเป็นอย่างไรหากเบราว์เซอร์ของฉันถอดรหัสไฟล์ไม่ได้

การถอดรหัสขึ้นอยู่กับเบราว์เซอร์ของคุณ: Chrome และ Edge ถอดรหัสได้กว้างที่สุด Safari จัดการ M4A/AAC ได้โดยกำเนิด ส่วน Firefox ถอดรหัส M4A/AAC ไม่ได้ หากไฟล์ใดถอดรหัสไม่ได้ ให้ลองใช้เบราว์เซอร์อื่น

เครื่องมือเสียงที่เกี่ยวข้อง
