ตัวสร้างรูปคลื่นเสียง - เสียงเป็นภาพรูปคลื่นเสียง ออนไลน์ฟรี

กล่าวโดยสรุป: ตัวสร้างรูปคลื่นเสียงเปลี่ยนไฟล์เสียงใด ๆ ให้เป็นภาพรูปคลื่นเสียงที่สะอาด - คุณเลือกขนาด สี สไตล์แบบทึบหรือแบบแท่ง และว่าพื้นหลังโปร่งใสหรือไม่ - จากนั้นดาวน์โหลดมันเป็น PNG ฟรีทั้งหมด และไฟล์ของคุณไม่เคยออกจากอุปกรณ์ของคุณ

ภาพปกพอดแคสต์ ภาพขนาดย่อของวิดีโอ สไลด์บทเรียน และโพสต์โซเชียลล้วนดูดีขึ้นเมื่อมีรูปร่างจริงของเสียงอยู่บนพวกมัน โหลดไฟล์เสียงแล้วเครื่องมือนี้จะวาดรูปคลื่นเสียงจริงของมัน - วัดทีละแซมเปิลจากไฟล์ของคุณ ไม่ใช่ของตกแต่ง - พร้อมวางลงในการออกแบบใดก็ได้

เป็นส่วนตัวโดยการออกแบบ: ไฟล์เสียงของคุณถูกถอดรหัสและวาด 100% ในเบราว์เซอร์ของคุณด้วย Web Audio API มันไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และเราไม่เคยได้ยินมัน - ปิดแท็บแล้วทุกอย่างก็หายไป

วิธีใช้เครื่องมือนี้

  1. คลิกช่องด้านบนหรือลากไฟล์เสียงของคุณเข้าไป - MP3, WAV, M4A และ OGG ใช้ได้ทั้งหมด รูปคลื่นเสียงแรกจะปรากฏขึ้นโดยอัตโนมัติ
  2. เลือกความกว้างและความสูงของภาพ สไตล์แบบทึบหรือแบบแท่ง และสีของรูปคลื่นเสียงและพื้นหลัง - หรือติ๊กตัวเลือกพื้นหลังโปร่งใสสำหรับการซ้อนทับ
  3. ทุกการเปลี่ยนแปลงจะวาดภาพใหม่ทันที ดังนั้นปรับแต่งไปจนกว่าจะเข้ากับดีไซน์ของคุณ
  4. กด "ดาวน์โหลด PNG" และใช้ภาพนั้นได้ทุกที่ - ภาพปก สไลด์ ภาพขนาดย่อ และโพสต์

คำถามที่พบบ่อย

ตัวสร้างรูปคลื่นเสียงฟรีหรือไม่

ใช่ มันฟรีทั้งหมดโดยไม่ต้องสมัครสมาชิก ไม่มีลายน้ำ และไม่มีขีดจำกัดที่เรากำหนด

ไฟล์เสียงของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่

ไม่ ไฟล์ของคุณถูกถอดรหัสและวาด 100% ภายในเบราว์เซอร์ของคุณด้วย Web Audio API มันไม่เคยออกจากอุปกรณ์ของคุณ

รูปคลื่นเสียงเป็นรูปร่างจริงของเสียงของฉันหรือไม่

ใช่ เครื่องมือวัดแซมเปิลต่ำสุดและสูงสุดในทุกคอลัมน์ของไฟล์จริงของคุณและวาดค่าที่แน่นอนเหล่านั้น - ส่วนที่ดังจะวาดสูง ส่วนที่เบาจะวาดสั้น ความเงียบจะวาดราบเรียบ

พื้นหลังโปร่งใสมีไว้เพื่ออะไร

เมื่อติ๊กความโปร่งใสไว้ PNG จะไม่มีพื้นหลังเลย ดังนั้นคุณจึงวางรูปคลื่นเสียงซ้อนบนภาพถ่าย สไลด์สี หรือภาพขนาดย่อของวิดีโอได้ และมีเพียงรูปร่างของรูปคลื่นเสียงเท่านั้นที่แสดง

ฉันสร้างขนาดภาพใดได้บ้าง

ความกว้าง 1200, 1600 หรือ 2400 พิกเซล และความสูง 300, 400 หรือ 600 พิกเซล - ใหญ่พอสำหรับภาพปก สไลด์ และภาพโซเชียล ขณะที่ยังคงสร้างได้อย่างรวดเร็วบนทุกอุปกรณ์

วิธีการทำงาน

ไฟล์ของคุณถูกเปิดภายในเบราว์เซอร์ของคุณโดยตรงและถอดรหัสเป็นแซมเปิลเสียงดิบด้วย Web Audio API - ไม่มีอะไรถูกอัปโหลดไปยังเซิร์ฟเวอร์ใด ๆ แซมเปิลจะถูกแบ่งออกเป็นคอลัมน์ตามจำนวนเท่ากับความกว้างของภาพที่คุณเลือก แซมเปิลต่ำสุดและสูงสุดในแต่ละคอลัมน์จะถูกวัด และยอดเหล่านั้นจะถูกวาดบนผืนผ้าใบในสไตล์และสีที่คุณเลือก ไฟล์ PNG ที่คุณดาวน์โหลดถูกส่งออกโดยตรงจากผืนผ้าใบนั้น

ไฟล์สเตอริโอถูกวาดเป็นรูปคลื่นเสียงรวมเพียงภาพเดียว: แต่ละคอลัมน์แสดงยอดที่สูงที่สุดจากช่องใดช่องหนึ่ง ซึ่งเป็นรูปร่างที่ภาพปกและภาพขนาดย่อส่วนใหญ่ใช้

ตัวอย่างที่ทำจริง

ครูคนหนึ่งทำบทเรียนเสียงความยาว 2 นาทีเสร็จ และต้องการภาพปกสำหรับกลุ่มชั้นเรียน เธอโหลดไฟล์ MP3 เลือกขนาด 1600 x 400 รูปคลื่นเสียงแบบทึบสีเขียวเข้มบนพื้นสีขาว และดาวน์โหลดไฟล์ PNG ในสไลด์ของเธอ รูปคลื่นเสียงอยู่ใต้ชื่อบทเรียน - และสองส่วนที่สูงโดดเด่นของมันก็คือสองช่วงที่เธอยกเสียงขึ้นสำหรับประเด็นสำคัญพอดี

คำถามเพิ่มเติม

ฉันสร้างรูปคลื่นเสียงสำหรับเฉพาะบางส่วนของไฟล์ได้หรือไม่

ตัดไฟล์ก่อนด้วยตัวตัดไฟล์เสียง จากนั้นโหลดไฟล์ WAV ที่ตัดแล้วที่นี่ - ภาพจะแสดงส่วนนั้นพอดี

ทำไมรูปคลื่นเสียงของฉันจึงดูราบเรียบในบางที่

ส่วนที่ราบเรียบคือส่วนของไฟล์บันทึกที่เงียบหรือแทบไม่มีเสียงจริง ๆ - ภาพที่วาดซื่อตรงต่อเสียง หากภาพทั้งหมดดูเล็กและราบเรียบ แปลว่าไฟล์บันทึกนั้นเงียบโดยรวม ตัวเพิ่มระดับเสียงสามารถเร่งระดับของมันก่อนได้

ฉันดาวน์โหลดภาพเป็น JPG แทน PNG ได้หรือไม่

เครื่องมือส่งออกเป็น PNG เพราะ PNG รองรับตัวเลือกพื้นหลังโปร่งใสและรักษาขอบให้คมชัด โปรแกรมแก้ไขภาพหรือตัวแปลงใดก็ได้สามารถเปลี่ยน PNG เป็น JPG ได้ในไม่กี่วินาทีหากงานออกแบบต้องการมัน
