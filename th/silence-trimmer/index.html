ตัวตัดช่วงเงียบ - ลบความเงียบออกจากเสียง ออนไลน์ฟรี

กล่าวโดยสรุป: ตัวตัดช่วงเงียบลบช่วงที่เงียบที่ตอนต้นและตอนท้ายของไฟล์บันทึก - มันแสดงให้คุณเห็นอย่างแม่นยำว่ามันพบความเงียบกี่วินาทีที่แต่ละปลายก่อนที่คุณจะดาวน์โหลดไฟล์ WAV ที่ตัดแล้ว ฟรีทั้งหมด และไฟล์ของคุณไม่เคยออกจากอุปกรณ์ของคุณ

ไฟล์บันทึกจากโทรศัพท์และไมโครโฟนเกือบทุกไฟล์เริ่มต้นด้วยความเงียบอันงุ่มง่ามไม่กี่วินาทีและจบลงในแบบเดียวกัน เครื่องมือนี้วัดปลายด้านที่เงียบเหล่านั้นอย่างตรงไปตรงมา - เป็นหน่วยวินาที ที่ค่าเกณฑ์ซึ่งคุณเป็นผู้ควบคุม - และตัดพวกมันออก โดยเผื่อระยะปลอดภัยเล็ก ๆ ไว้ เพื่อให้คำแรกและคำสุดท้ายไม่เคยถูกตัดทิ้ง

เป็นส่วนตัวโดยการออกแบบ: ไฟล์เสียงของคุณถูกถอดรหัสและวัด 100% ในเบราว์เซอร์ของคุณด้วย Web Audio API มันไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และเราไม่เคยได้ยินมัน - ปิดแท็บแล้วทุกอย่างก็หายไป

วิธีใช้เครื่องมือนี้

  1. คลิกช่องด้านบนหรือลากไฟล์เสียงของคุณเข้าไป - MP3, WAV, M4A และ OGG ใช้ได้ทั้งหมด
  2. อ่านผลการวิเคราะห์: พบความเงียบตอนต้นเท่าไร ตอนท้ายเท่าไร และคุณเก็บเสียงไว้เท่าไร
  3. ปรับค่าเกณฑ์หากจำเป็น - ค่าที่ต่ำกว่า (เช่น -60 dB) จะลบเฉพาะความเงียบที่แท้จริงเท่านั้น ส่วนค่าที่สูงกว่า (เช่น -30 dB) จะลบเสียงบรรยากาศในห้องที่เงียบไปด้วย - และตั้งค่าว่าจะเผื่อระยะไว้เท่าไร
  4. คลิก "ดาวน์โหลด WAV ที่ตัดแล้ว" จากนั้นฟังไฟล์ที่ตัดแล้วในเครื่องเล่นเพื่อตรวจสอบปลายทั้งสองด้าน

คำถามที่พบบ่อย

ตัวตัดช่วงเงียบฟรีหรือไม่

ใช่ มันฟรีทั้งหมดโดยไม่ต้องสมัครสมาชิก ไม่มีลายน้ำ และไม่มีขีดจำกัดที่เรากำหนด

ไฟล์เสียงของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่

ไม่ ไฟล์ของคุณถูกถอดรหัสและตัด 100% ภายในเบราว์เซอร์ของคุณด้วย Web Audio API มันไม่เคยออกจากอุปกรณ์ของคุณ

ค่าเกณฑ์ dB หมายความว่าอย่างไร

มันคือระดับที่ต่ำกว่านั้นเสียงจะนับเป็นความเงียบ -40 dB (แนะนำสำหรับเสียงพูด) ถือว่าอะไรก็ตามที่เงียบกว่า 1% ของระดับเสียงเต็มเป็นความเงียบ -60 dB ลบเฉพาะความเงียบดิจิทัลที่เกือบสมบูรณ์เท่านั้น ขณะที่ -20 dB นั้นรุนแรงและอาจกินปลายเสียงพูดที่เบาไปได้

คำแรกหรือคำสุดท้ายของฉันจะถูกตัดออกหรือไม่

การตั้งค่าระยะเผื่อจะเก็บเสียงส่วนเกินไว้ที่ปลายทั้งสองด้าน - 0.1 วินาทีโดยค่าเริ่มต้น - ดังนั้นจุดเริ่มต้นของคำตามธรรมชาติและการเฟดออกจะคงอยู่ หากไฟล์บันทึกมีจุดเริ่มต้นที่เบามาก ให้เพิ่มระยะเผื่อเป็น 0.3-0.5 วินาที

มันลบความเงียบตรงกลางไฟล์ด้วยหรือไม่

ไม่ เครื่องมือนี้ตัดเฉพาะตอนต้นและตอนท้ายเท่านั้น ช่วงหยุดตรงกลางเป็นส่วนหนึ่งของไฟล์บันทึกและถูกปล่อยไว้อย่างที่เป็นอยู่อย่างแน่นอน

วิธีการทำงาน

ไฟล์ของคุณถูกเปิดภายในเบราว์เซอร์ของคุณโดยตรงและถอดรหัสเป็นแซมเปิลเสียงดิบด้วย Web Audio API - ไม่มีอะไรถูกอัปโหลดไปยังเซิร์ฟเวอร์ใด ๆ เครื่องมือสแกนจากจุดเริ่มต้นจนกว่าจะพบแซมเปิลแรกที่ดังกว่าค่าเกณฑ์ของคุณ และจากจุดสิ้นสุดย้อนกลับมายังแซมเปิลที่ดังตัวสุดท้าย ทุกอย่างที่อยู่นอกเหนือสองจุดนั้นคือความเงียบที่กำลังถูกลบออก ระยะเผื่อที่คุณเลือกจะถูกเพิ่มกลับเข้าไปในแต่ละด้าน

เพราะการวัดทำงานบนแซมเปิลจริง ตัวเลขที่แสดง - ความเงียบตอนต้น ความเงียบตอนท้าย จำนวนวินาทีที่เก็บไว้ - จึงแม่นยำสำหรับค่าเกณฑ์ที่คุณเลือก ไม่ใช่ค่าประมาณ เปลี่ยนค่าเกณฑ์แล้วผลการวิเคราะห์จะอัปเดตทันที เพื่อให้คุณเห็นข้อแลกเปลี่ยนก่อนดาวน์โหลด

ตัวอย่างที่ทำจริง

คุณบันทึกบทเรียนความยาว 3 นาทีบนโทรศัพท์ของคุณ: ความเงียบ 4 วินาทีก่อนที่คุณจะเริ่มพูด และ 6 วินาทีตอนท้ายขณะที่คุณเอื้อมมือไปกดปุ่มหยุด การวิเคราะห์แสดงตามนั้นเป๊ะ ๆ ด้วยค่าเกณฑ์ -40 dB และระยะเผื่อ 0.1 วินาที คุณดาวน์โหลดไฟล์ WAV ที่สะอาดความยาว 2 นาที 50 วินาทีซึ่งเริ่มต้นและจบลงด้วยเสียงของคุณ

คำถามเพิ่มเติม

ทำไมเครื่องมือจึงบอกว่าไฟล์ทั้งหมดของฉันคือความเงียบ

ทุกแซมเปิลในไฟล์อยู่ต่ำกว่าค่าเกณฑ์ที่เลือก - ไม่ไฟล์บันทึกนั้นเงียบจริง ๆ หรือเงียบมาก ๆ ก็ค่าเกณฑ์ถูกตั้งไว้สูงเกินไปสำหรับมัน ลดค่าเกณฑ์ลงเป็น -50 หรือ -60 dB แล้วการวิเคราะห์จะทำงานอีกครั้ง

ฉันต้องการลบช่วงหยุดตรงกลางด้วย ทำอย่างไร

ตัดไฟล์ออกเป็นชิ้น ๆ ด้วยตัวตัดไฟล์เสียง โดยเก็บส่วนก่อนและหลังช่วงหยุดไว้ จากนั้นรวมพวกมันกลับเข้าด้วยกันด้วยตัวรวมไฟล์เสียง

ทำไมไฟล์ดาวน์โหลดจึงออกมาเป็น WAV

WAV คือรูปแบบที่เบราว์เซอร์ของคุณสร้างได้โดยกำเนิดโดยไม่ต้องใช้ซอฟต์แวร์เพิ่มเติม และมันเก็บเสียงไว้อย่างที่ถอดรหัสทุกประการ ใช้ตัวแปลงไฟล์เสียงหากคุณต้องการไฟล์ที่ตัดแล้วเป็น MP3 ในภายหลัง
