ตัวเพิ่มระดับเสียง - ทำให้เสียงดังขึ้น ออนไลน์ฟรี

กล่าวโดยสรุป: ตัวเพิ่มระดับเสียงทำให้เสียงที่เบาดังขึ้น - สูงสุด 300% ของระดับเสียงเดิม - พร้อมคำเตือนเรื่องเสียงแตกแบบสดเพื่อไม่ให้คุณทำลายเสียง บวกกับตัวเลือกปรับให้เป็นปกติในคลิกเดียวที่เร่งระดับเสียงให้ไกลที่สุดเท่าที่ปลอดภัย

บันทึกเสียงที่อัดมาไกลจากไมโครโฟนเกินไป บทบรรยายที่คุณแทบไม่ได้ยิน วิดีโอที่เสียงเบาเหมือนเสียงกระซิบ - เครื่องมือนี้ช่วยเร่งระดับเสียงให้คุณ ลากแถบเลื่อน ตรวจสอบตัวอย่าง คอยดูคำเตือนเรื่องเสียงแตก และดาวน์โหลดเสียงที่ดังขึ้นเป็นไฟล์ WAV

เป็นส่วนตัวโดยการออกแบบ: ไฟล์เสียงของคุณถูกถอดรหัสและเร่งเสียง 100% ในเบราว์เซอร์ของคุณด้วย Web Audio API มันไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และเราไม่เคยได้ยินมัน - ปิดแท็บแล้วทุกอย่างก็หายไป

วิธีทำให้ไฟล์เสียงดังขึ้น

  1. คลิกช่องด้านบนหรือลากไฟล์เสียงของคุณเข้าไป - MP3, WAV, M4A และ OGG ใช้ได้ทั้งหมด เครื่องมือจะแสดงระดับยอดสูงสุดปัจจุบันของไฟล์
  2. ลากแถบเลื่อนระดับเสียงขึ้น - 200% คือความดังระดับแซมเปิลเป็นสองเท่า ส่วน 300% คือการเร่งสูงสุด
  3. หากคำเตือนเรื่องเสียงแตกสีแดงปรากฏขึ้น ให้ลดแถบเลื่อนลง หรือติ๊ก "ปรับให้เป็นปกติแทน" เพื่อเร่งระดับเสียงอย่างปลอดภัยไปถึงระดับสูงสุดโดยไม่เกิดเสียงเพี้ยน
  4. ฟังตัวอย่างด้วย "เล่นตัวอย่างที่เร่งเสียงแล้ว" จากนั้นคลิก "ดาวน์โหลด WAV ที่เร่งเสียงแล้ว"

คำถามที่พบบ่อย

ตัวเพิ่มระดับเสียงฟรีหรือไม่

ใช่ มันฟรีทั้งหมดโดยไม่ต้องสมัครสมาชิก ไม่มีลายน้ำ และไม่มีขีดจำกัดที่เรากำหนด

ไฟล์เสียงของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่

ไม่ ไฟล์ของคุณถูกถอดรหัสและเร่งเสียง 100% ภายในเบราว์เซอร์ของคุณด้วย Web Audio API มันไม่เคยออกจากอุปกรณ์ของคุณ

การตัดขาด (clipping) คืออะไร และทำไมจึงมีคำเตือน

เสียงดิจิทัลมีระดับสูงสุดที่ 100% หากการเร่งเสียงดันแซมเปิลเลยขีดจำกัดนั้น พวกมันจะถูกตัดราบเรียบ - นั่นคืออาการเสียงแตก (clipping) และฟังดูเหมือนเสียงเพี้ยนที่หยาบกระด้าง คำเตือนจะปรากฏขึ้นทุกครั้งที่การเร่งเสียงที่คุณเลือกจะดันยอดเสียงที่ดังที่สุดเลย 100% เพื่อให้คุณลดการเร่งลงหรือใช้การปรับให้เป็นปกติก่อนที่มันจะเกิดขึ้น

การปรับให้เป็นปกติทำอะไร

การปรับให้เป็นปกติวัดช่วงที่ดังที่สุดในไฟล์ทั้งหมดและปรับขนาดทุกอย่างเพื่อให้ยอดนั้นลงที่ 100% พอดี - ดังที่สุดเท่าที่ไฟล์จะเป็นได้โดยไม่มีเสียงแตกเลย ไฟล์บันทึกที่เสียงเบาและมีช่วงดังเพียงช่วงเดียวจะไม่เพิ่มขึ้นมากนัก ส่วนไฟล์บันทึกที่เสียงเบาสม่ำเสมอจะเพิ่มขึ้นมาก

300% คือกี่เดซิเบล

ระดับเสียง 300% อยู่ที่ประมาณ +9.5 dB ส่วน 200% อยู่ที่ประมาณ +6 dB และ 50% อยู่ที่ประมาณ -6 dB เครื่องมือจะแสดงค่า dB ที่แน่นอนข้างแถบเลื่อนขณะที่คุณลาก

วิธีการทำงาน

ไฟล์ของคุณถูกเปิดภายในเบราว์เซอร์ของคุณโดยตรงและถอดรหัสเป็นแซมเปิลเสียงดิบด้วย Web Audio API - ไม่มีอะไรถูกอัปโหลดไปยังเซิร์ฟเวอร์ใด ๆ เครื่องมือวัดแซมเปิลที่สูงที่สุดในไฟล์ (ยอดของมัน) คูณทุกแซมเปิลด้วยเกนที่คุณเลือกในการเรนเดอร์แบบออฟไลน์ เตือนคุณหากผลลัพธ์จะผ่านเพดานดิจิทัล 100% และบันทึกผลลัพธ์เป็นไฟล์ WAV

ตัวอย่างที่ทำจริง

คุณบันทึกบทสัมภาษณ์บนโทรศัพท์ของคุณและช่วงที่ดังที่สุดไปถึงเพียง 30% ของระดับสูงสุดเท่านั้น คุณโหลดไฟล์ และแทนที่จะเดาค่าแถบเลื่อน คุณติ๊ก "ปรับให้เป็นปกติแทน" บทสัมภาษณ์ทั้งหมดจะถูกปรับขนาดขึ้นประมาณ 3.3 เท่าเพื่อให้ยอดของมันไปถึง 100% พอดี - ตอนนี้ทุกคำดังเท่าที่จะเป็นได้อย่างปลอดภัย โดยไม่มีเสียงเพี้ยน และคุณดาวน์โหลดไฟล์ WAV

ทั้งการเร่งเสียงและการปรับให้เป็นปกติต่างก็เร่งเสียงรบกวนขึ้นไปพร้อมกับเสียงพูด ดังนั้นให้เริ่มจากไฟล์บันทึกที่สะอาดที่สุดที่คุณมี

คำถามเพิ่มเติม

การเร่งเสียงจะลบเสียงรบกวนรอบข้างหรือไม่

ไม่ - การเร่งเสียงทำให้ทุกอย่างดังขึ้นพร้อมกัน รวมถึงเสียงซ่าหรือเสียงในห้องที่มีอยู่ในไฟล์บันทึกต้นฉบับ มันทำความสะอาดเสียงไม่ได้ มันทำได้เพียงเร่งระดับเสียงเท่านั้น

ทำไมไฟล์ที่ดาวน์โหลดจึงใหญ่กว่า MP3 ของฉัน

การส่งออกเป็น WAV ซึ่งเป็นรูปแบบไม่บีบอัดที่เบราว์เซอร์ของคุณสร้างได้โดยกำเนิด มันเก็บเสียงไว้อย่างที่เรนเดอร์ทุกประการ แต่ไฟล์มีขนาดใหญ่กว่า MP3 ตัวแปลงมาตรฐานตัวใดก็ได้สามารถเปลี่ยน WAV เป็น MP3 ได้ในภายหลัง

ไฟล์บันทึกของฉันดังในที่หนึ่งและเบาในอีกที่หนึ่ง ฉันควรทำอย่างไร

นั่นเป็นปัญหาเรื่องพลวัต ไม่ใช่ปัญหาเรื่องระดับเสียงธรรมดา การปรับให้เป็นปกติจะช่วยได้เพียงเล็กน้อย เพราะช่วงที่ดังเพียงช่วงเดียวเป็นตัวกำหนดขีดจำกัด การตัดออกหรือเร่งเฉพาะส่วนที่เงียบด้วยตัวตัดไฟล์เสียงมักทำงานได้ดีกว่า
