About this tool

MP3 is the format of distribution; WAV is the format of editing. Converting MP3 to WAV does not improve the sound — the quality lost in MP3 compression is gone — but it gives you an uncompressed file that every editor, sampler and DAW opens without decoding, and that you can edit and re-export without a second round of lossy compression.

WAV files are large (about 10 MB per minute at CD quality), so this conversion makes sense when the file is going into an editor, a video project or a sampler — not for storing music, where MP3 is the right size.

Worked example

A teacher pulls a 3-minute MP3 clip into her video editor, which rejects MP3 on import. She converts it here to WAV, the editor accepts it, and the voiceover lands exactly on the timeline.

Frequently asked questions

Will the quality change?

Converting to WAV is lossless — the decoded samples are written out exactly. Converting to MP3 is lossy: the file shrinks, but some detail is discarded permanently. Converting MP3 to WAV does not restore lost quality; it only changes the container.

Is my audio file private?

Yes. Decoding and encoding happen 100% in your browser with the Web Audio API and a local MP3 encoder. The file is never uploaded, stored or heard by us.

What if my browser cannot decode the file?

Decoding depends on your browser: Chrome and Edge decode the widest range; Safari handles M4A/AAC natively; Firefox does not decode M4A/AAC. If a file will not decode, try another browser.
